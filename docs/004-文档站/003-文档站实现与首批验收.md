## 1. 结果

首批文档站已经落地，可直接构建为静态产物。站点以“截至当前重构提交的进度”为主线，包含：

- 落地页：定位、规模快照、阶段进展、能力主线、兼容四层、架构、代码入口与边界声明。
- 进度看板：从 Git、`coverage.out`、端点对照表与能力矩阵生成事实。
- 能力矩阵：17 项能力的四列证据，可筛选、展开限制、导出 JSON。
- REST 浏览器：242 个方法端点的搜索、域/方法/来源筛选与分页。
- 50 篇 Markdown 文档：开始使用、进度、架构、Go SDK、REST、兼容性、迁移、运维、参考、发布。
- 全文搜索、亮/暗主题、移动端目录、代码复制、上下篇导航、链接与锚点构建期校验。

站点没有把“路由存在”写成“兼容通过”。落地页与看板均明确单执行者、Java 对照未完成、停写/回退未演练。

## 3. 技术实现

### 3.1 构建期内容管线

`npm run build` 先执行 `npm run gen`：

1. `gen-facts.mjs` 读取 Git、Go 源码、`coverage.out`、REST 对照表、能力矩阵与 Schema，输出 `facts.json`。
2. `gen-content.mjs` 读取 `src/content/**/*.md`，解析 frontmatter，使用 markdown-it + Shiki 生成 HTML、标题锚点与搜索文本。
3. 生成器校验路由唯一性、frontmatter、标题锚点唯一性与站内链接/锚点。
4. Vite 构建 Vue 单页应用，按路由懒加载页面组件。

生成物位于 `src/generated/`，加入 `.gitignore`，避免与源码漂移。

### 3.2 页面与路由

| 路由 | 页面 | 数据 |
| --- | --- | --- |
| `/` | LandingPage | facts + 静态曲线 |
| `/progress` | ProgressPage | facts + 能力矩阵 |
| `/compatibility` | CompatibilityPage | facts.capabilities |
| `/rest-explorer` | RestExplorerPage | facts.rest.endpoints |
| `/docs` | DocsIndexPage | content.pages |
| `/docs/{section}/{slug}` | DocPage | content.pages |
| `/releases` | DocPage（frontmatter 覆盖路由） | releases/index.md |

### 3.3 搜索与主题

- MiniSearch 纯前端索引，中文按二元组切分，英文按词切分；查询命中分区名时优先返回分区落地页。
- 顶部 `Ctrl/Cmd + K` 唤起搜索面板，支持方向键、回车、Esc。
- 主题写入 `localStorage` 与 `documentElement.dataset.theme`；Naive UI 通过 `darkTheme` 同步。
- 代码块使用 Shiki 双主题变量，亮/暗模式只切换 CSS 变量。

### 3.4 事实口径

| 事实 | 口径 |
| --- | --- |
| 提交数/日期 | `git rev-list --count HEAD`、`git log -1` |
| Go 文件/行数 | 扫描仓库内 `.go`，排除依赖与构建产物 |
| 测试/基准函数 | `*_test.go` 中 `Test/Benchmark/Fuzz` 声明数 |
| 覆盖率 | `coverage.out` 语句加权 |
| 端点 | 004 对照表，方法 + 规范化路径 |
| 能力矩阵 | 003 表格，发布状态保守归类 |
| ACT 表 | MySQL DDL 的 `create table` 计数 |

覆盖率来自仓库已有 `coverage.out`；需要最新数据时应先运行 `make cover`。

## 6. 运行与部署

~~~bash
cd docs-site
npm install
npm run dev          # 本地开发
npm run build        # 静态构建
npm run preview      # 预览 dist
~~~

`dist/` 为纯静态产物。history 路由部署需要 SPA fallback（Nginx `try_files $uri $uri/ /index.html;`）。当前没有版本快照、英文版与 OpenAPI 浏览器。

## 7. 已知限制

1. 内容静态生成；编辑 Markdown 后需重新 `npm run gen` 或重启 dev。
2. 覆盖率取 `coverage.out`，不是构建时实时运行 `make cover`。
3. 能力矩阵与端点表来自仓库文档；文档漂移不会被站点自动发现。
4. E2E 与截图未纳入 CI；CI 只跑单元测试与生产构建。
5. 未做 Lighthouse、axe、跨浏览器与完整键盘可达性审计。
6. 首批 50 页，未覆盖 001/002 规划的全部 79 页；SDK 生成 API 参考、OpenAPI 浏览器、版本快照、i18n、容器部署页仍待补。
7. 页面状态标签为编辑判断；只有快速开始等命令在 2026-10-29 实际复跑。
