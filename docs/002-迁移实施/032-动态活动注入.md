# 032 动态活动注入

> 文档编号：002-032  
> 更新日期：2026-10-28  
> 对应计划：006 流程执行引擎 PVM 设计；011 REST API 与兼容契约

## 1. 背景

Flowable 支持在运行实例中动态注入用户任务/子流程，用于临时审批、人工补救等场景。本期实现安全子集：**动态用户任务**。

与 Flowable 动态 BPMN 的差异：本实现不修改流程定义，而是创建一个“实例内独立任务”，完成该任务不会推进主流程令牌。

## 2. 端点

`POST /service/runtime/process-instances/{id}/inject`

请求：

~~~json
{
  "injectionType": "task",
  "name": "Review",
  "assignee": "bob",
  "id": "optional-task-id",
  "taskId": "existing-task-id"
}
~~~

字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| injectionType | 否 | 空或 `task`；其他类型 400 |
| name | 是 | 任务名称 |
| assignee | 否 | 处理人 |
| id | 否 | 指定任务 ID，重复 409 |
| taskId | 否 | 参考任务，必须属于同一实例；仅做校验 |

成功返回 200 与任务 DTO。

## 3. 语义

- 动态任务的 `processInstanceId` 与 `processDefinitionId` 取自实例，但 **无 executionId**。
- 任务出现在实例任务列表中，可认领、完成、加评论/附件/变量。
- 完成任务只结束该任务，不触发 `takeOutgoing`，主流程继续等待原有任务。
- 多次注入互不影响；可通过 `taskId` 声明与某个任务并行（当前仅校验归属）。
- 实例不存在 404；已结束/已挂起 409；名称为空 400。

## 4. 限制

1. 仅支持用户任务，`subprocess` 注入返回 400。
2. 不修改 BPMN 模型，不生成动态流程定义；实例迁移/流程图不包含注入任务。
3. 动态任务没有执行作用域，任务变量仅保存在任务局部变量与历史明细中，不写入执行变量。
4. 动态任务不参与边界事件、补偿与多实例。
5. 任务完成不会触发后续网关/连线。

## 5. 测试

- `internal/engine/inject_test.go`：注入、任务列表、完成不影响主流程、错误路径。
- `internal/rest/inject_test.go`：端点、任务完成、400/404。
- 覆盖率：`internal/engine` 90.7%，`internal/rest` 90.6%。
