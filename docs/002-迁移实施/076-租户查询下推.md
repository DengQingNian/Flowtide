# 076 租户查询下推

> 文档编号：002-076
> 更新日期：2026-10-30
> 对应任务：行仓储模式下任务、实例与历史实例查询的租户条件下推

## 1. 背景与目标

[062](062-任务查询下推.md) 与 [075](075-实例与历史查询下推.md) 完成默认租户下的查询下推，但租户过滤被明确排除：任务查询携带租户时以 `ROW-0035` 拒绝，实例与历史查询依赖 `hasNonDefaultTenantData` / `hasNonDefaultTenantHistory` 整体回退内存。能力矩阵将"租户下推"列为集群与容量阶段的未完成项。

本次将租户条件下推 SQL：

- `flowablerow.TaskQuery`、`ProcessInstanceQuery`、`HistoricProcessInstanceQuery` 的 `TenantID` 非空时追加 `TENANT_ID_ = ?` 等值条件；任务查询的 `ROW-0035` 拒绝删除；
- 引擎下推门禁重设计：生效租户（请求过滤租户优先，其次上下文/默认租户）非空时直接下推；仅当生效租户为空且内存存在非默认租户数据时整体回退内存（此时 SQL 无租户条件会把其他租户计入总数与分页）；
- `api.ProcessInstanceFilter`、`api.HistoricProcessInstanceFilter` 新增 `TenantID` 字段；内存回退匹配函数同步支持租户等值语义；
- REST 的实例、历史实例、任务查询把显式 `tenantId` 参数线程到引擎 filter；请求租户仍经引擎上下文生效。

## 2. 门禁语义

| 场景 | 075 及之前 | 本次之后 |
| --- | --- | --- |
| 生效租户为空、内存单租户 | 下推 SQL（无租户条件） | 不变 |
| 生效租户为空、内存多租户 | 回退内存 | 不变 |
| 生效租户非空（请求租户 / 绑定租户 / filter.TenantID） | 回退内存；任务查询直接拒绝 | 下推 SQL，追加 `TENANT_ID_ = ?` |
| 多租户数据 + 指定租户过滤 | 回退内存 | 下推 SQL，总数取该租户的 SQL 计数 |

租户条件与既有条件同批参数化；`allowTenant` 租户可见性校验在下推映射时保留，不因下推绕过。

## 3. SQL 形状

```sql
-- 任务（ACT_RU_TASK T）
... AND T.TENANT_ID_ = ?
-- 运行时实例（ACT_RU_EXECUTION E，实例根 E.PARENT_ID_ IS NULL）
... AND E.TENANT_ID_ = ?
-- 历史实例（ACT_HI_PROCINST H）
... AND H.TENANT_ID_ = ?
```

三张表的标准行导出均携带 `TENANT_ID_`（默认租户为空串）；等值条件与内存 `item.TenantID != filterTenant` 语义一致。

## 4. 边界与未下推

- 请求租户（中间件绑定）由引擎上下文生效并下推；显式 `tenantId` 参数经 filter 生效；两者同时存在时 filter 租户优先构造 SQL 条件，REST 内存过滤仍按各自语义复核。
- 未绑定租户的请求对非默认租户数据的可见性语义不变：生效租户为空且存在多租户数据时仍回退内存，由 `allowTenant` 屏蔽。
- 无租户变体（如 `withoutTenantId`）与租户集合过滤不在本次范围。
- `ROW-0035`（租户过滤尚未下推）错误码随该拒绝路径删除；其余错误码不变。

- 持久化：`TestQueryTaskIDs_TenantPushdown`（原拒绝用例改写下推）验证 `TENANT_ID_ = ?` 的 COUNT+SELECT 文本与参数；实例/历史查询的租户条件由既有逐列用例模式覆盖。
