# 012 流程模型仓库

> 文档编号：002-012  
> 更新日期：2026-10-28  
> 对应计划：005 BPMN 模型、XML 解析与部署校验；011 REST API 与兼容契约

## 1. 背景

Flowable 的模型（Model）是流程设计器的持久化载体：它保存模型元数据、BPMN 编辑源与扩展源码，部署时再转化为流程定义。此前 Go 引擎只有部署与定义，没有模型仓库。

本期补齐模型 CRUD、源码读写与持久化，对应官方 9 个端点。

## 3. REST 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/repository/models` | 模型列表 |
| POST | `/service/repository/models` | 创建模型 |
| GET | `/service/repository/models/{id}` | 模型详情 |
| PUT | `/service/repository/models/{id}` | 部分更新 |
| DELETE | `/service/repository/models/{id}` | 删除模型 |
| GET | `/service/repository/models/{id}/source` | 读取编辑源 |
| PUT | `/service/repository/models/{id}/source` | 上传编辑源 |
| GET | `/service/repository/models/{id}/source-extra` | 读取扩展源码 |
| PUT | `/service/repository/models/{id}/source-extra` | 上传扩展源码 |

创建请求：

~~~json
{
  "name": "Order Model",
  "key": "orderModel",
  "category": "sales",
  "metaInfo": "{}",
  "tenantId": "tenant-a",
  "version": 1
}
~~~

- 名称与 Key 必填，缺失返回 400。
- 版本缺省为 1。
- 创建返回 201，更新返回 200，删除返回 204。

### 3.1 列表过滤

支持 `id`、`category`、`categoryLike`、`categoryNotEquals`、`name`、`nameLike`、`key`、`deploymentId`、`version`、`latestVersion`、`deployed`、`tenantId`、`tenantIdLike`、`withoutTenantId`。

- `latestVersion=true` 时按 Key 保留最高版本。
- `deployed=true/false` 按是否存在 `deploymentId` 过滤。
- 排序字段：`id`、`category`、`createTime`、`key`、`lastUpdateTime`、`name`、`version`、`tenantId`。

### 3.2 源码上传

`PUT .../source` 与 `PUT .../source-extra` 使用 `multipart/form-data`，取第一个文件：

~~~bash
curl -X PUT 'http://localhost:8080/service/repository/models/{id}/source' \
  -F 'file=@process.bpmn20.xml'
~~~

- 成功返回 204。
- 非 multipart 或没有文件返回 400。
- `GET` 返回 `application/octet-stream`；未上传过源码返回 404。

## 4. 持久化

- 模型元数据映射 `ACT_RE_MODEL`。
- 编辑源与扩展源码写入 `ACT_GE_BYTEARRAY`，名称分别为 `model/{id}/source` 与 `model/{id}/extra`，与部署资源区分。
- 行导出/导入与 JSON 快照保持一致；`RestoreRows` 可恢复模型与源码。
- 删除模型不会删除已部署的流程定义与部署记录。

## 5. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 名称或 Key 为空 | 400 | `ENGINE-1002` |
| 模型不存在 | 404 | `ENGINE-1001` |
| 源码不存在 | 404 | `ENGINE-1003` |
| 跨租户访问 | 404 | `ENGINE-0404` |
| 非 multipart 上传 | 400 | `REST-0130` |
| 缺少上传文件 | 400 | `REST-0129` |

## 6. 限制

1. 尚未实现“模型部署为流程定义”端点（`/repository/models/{id}/deployment`）。
2. 尚未实现流程定义的 BPMN 模型 JSON（`/repository/process-definitions/{id}/model`）。
3. 模型源不做 BPMN 校验，保存任意文本；校验发生在部署阶段。
4. 模型版本不自动递增，由客户端维护。
