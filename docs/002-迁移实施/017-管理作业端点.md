# 017 管理作业端点

> 文档编号：002-017  
> 更新日期：2026-10-28  
> 对应计划：009 作业、定时器与异步执行；011 REST API 与兼容契约

## 1. 背景

Flowable 将作业分为可执行作业、定时器作业、挂起作业、历史作业与死信作业。此前只有 `/management/jobs` 与 `/management/deadletter-jobs`，缺少分类列表、异常栈与删除能力。

本期补齐 11 个管理作业路由：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/management/timer-jobs` | 定时器作业列表 |
| GET | `/management/timer-jobs/{id}` | 定时器作业详情 |
| GET | `/management/timer-jobs/{id}/exception-stacktrace` | 定时器异常栈 |
| GET | `/management/suspended-jobs` | 挂起作业列表 |
| GET | `/management/suspended-jobs/{id}` | 挂起作业详情 |
| GET | `/management/suspended-jobs/{id}/exception-stacktrace` | 挂起作业异常栈 |
| GET | `/management/history-jobs` | 历史作业列表 |
| GET | `/management/history-jobs/{id}` | 历史作业详情 |
| DELETE | `/management/jobs/{id}` | 删除可执行作业 |
| GET | `/management/jobs/{id}/exception-stacktrace` | 作业异常栈 |
| GET | `/management/deadletter-jobs/{id}/exception-stacktrace` | 死信异常栈 |

## 2. 分类语义

- **定时器作业**：类型包含 `timer`（`boundary-timer`、`timer-start`、`timer-catch`）。
- **挂起作业**：所属流程实例 `suspended=true` 的作业；定时器作业挂起后从 `timer-jobs` 列表移出。
- **历史作业**：异步历史尚未实现，固定返回空列表，详情返回 404。
- **死信作业**：沿用已有死信表。
- **可执行作业**：`state.Jobs` 中的全部作业，包含定时器与异步作业。

## 3. 引擎 API

`ManagementService` 新增 `DeleteJob(ctx, jobID)`：

- 仅删除可执行作业。
- 作业不存在返回 404（`ENGINE-1501`）。
- 删除后不会再被作业扫描执行。

其余端点通过已有 `ListJobs`/`GetJob`/`GetDeadLetterJob` 组合过滤实现。

## 4. 异常栈

- 成功返回 `text/plain` 原始异常文本。
- 作业存在但没有异常信息返回 404（`ENGINE-1505`）。
- 作业不存在或分类不匹配返回 404。

## 5. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 作业不存在 | 404 | `ENGINE-1501` |
| 定时器作业不存在 | 404 | `ENGINE-1502` |
| 挂起作业不存在 | 404 | `ENGINE-1503` |
| 历史作业不存在 | 404 | `ENGINE-1504` |
| 作业无异常栈 | 404 | `ENGINE-1505` |

## 6. 限制

1. 挂起作业未复制到独立表，仍存放在 `state.Jobs`，仅通过实例挂起状态分类。
2. 历史作业（异步历史）未实现，端点固定为空。
3. 定时器作业列表按实例挂起状态动态过滤，恢复实例后自动回到定时器列表。
4. 异常栈为最近一次异常字符串，不是完整 JVM 栈。

## 7. 测试

- `internal/engine/job_admin_test.go`：作业删除与幂等。
- `internal/rest/jobs_extra_test.go`：定时器列表/详情/删除、挂起作业分类、历史作业空列表、异常栈 404。
- 覆盖率：`internal/engine` 90.5%，`internal/rest` 90.4%，`internal/persistence/flowable` 90.4%。
