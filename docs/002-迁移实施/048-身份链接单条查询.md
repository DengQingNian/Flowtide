# 048 身份链接单条查询

> 文档编号：002-048  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；011 REST API 与兼容契约

## 1. 背景

Flowable 支持按用户/组读取单个任务或实例身份链接，也支持带类型删除任务链接。此前只有列表与按族过滤。

本期补齐：

- `GET /runtime/tasks/{id}/identitylinks/{family}/{identityId}`
- `GET /runtime/process-instances/{id}/identitylinks/{family}/{identityId}`
- `DELETE /runtime/tasks/{id}/identitylinks/{family}/{identityId}/{type}`

## 2. 语义

`family`：

| 值 | 匹配字段 |
| --- | --- |
| `users` | `userId` |
| `groups` | `groupId` |

- 可选查询参数 `type` 用于进一步限定链接类型；路径中的 `type`（DELETE）当前忽略，仅保持 Flowable 路径兼容。
- 找到返回 200 + 链接；未找到 404。
- 任务链接支持 candidate 类型；实例链接支持 participant 等已有类型。
- 其他 family 返回 404（无匹配）。

## 3. 删除

`DELETE /runtime/tasks/{id}/identitylinks/{family}/{identityId}/{type}`

- 与两段路径版本行为一致：按 family + identityId 删除候选用户/组。
- 成功 204。

## 4. 限制

1. 路径 type 不参与删除条件（引擎删除接口按 family/identityId）。
2. 单条查询未实现租户参数。
3. 不支持一次性删除用户在所有任务上的链接。

## 5. 测试
