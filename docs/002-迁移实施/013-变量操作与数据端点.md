# 013 变量操作与数据端点

> 文档编号：002-013  
> 更新日期：2026-10-28  
> 对应计划：007 变量、表达式与脚本引擎；011 REST API 与兼容契约

## 1. 背景

变量是 Flowable REST 使用频率最高的资源之一。此前只支持实例级与任务级变量的单条增删改查，缺少：

- 执行（execution）作用域的变量读写。
- 批量变量更新与清空。
- 变量原始值下载（`/data`）。
- 历史变量按名称查询与原始值下载。
- 历史实例评论的创建与删除。

本期补齐这些能力，新增 16 个路由。

## 2. 引擎 API

`RuntimeService` 新增：

| 方法 | 说明 |
| --- | --- |
| `GetExecutionVariable(ctx, executionID, name)` | 读取执行可见变量 |
| `SetExecutionVariable(ctx, executionID, name, value)` | 写入执行局部变量 |
| `DeleteExecutionVariable(ctx, executionID, name)` | 删除执行局部变量 |
| `DeleteAllExecutionVariables(ctx, executionID)` | 清空执行局部变量 |
| `DeleteAllInstanceVariables(ctx, processInstanceID)` | 清空流程实例变量 |

`TaskService` 新增：

| 方法 | 说明 |
| --- | --- |
| `DeleteAllTaskVariables(ctx, taskID)` | 清空任务局部变量 |

`HistoryService` 新增：

| 方法 | 说明 |
| --- | --- |
| `GetHistoricDetail(ctx, detailID)` | 查询历史变量明细 |
| `GetHistoricVariableByName(ctx, processInstanceID, name)` | 按实例与名称取最新历史变量 |
| `GetHistoricTaskVariableByName(ctx, taskID, name)` | 按任务与名称取最新历史变量 |

执行变量写入会同步更新历史变量与变量明细；读取沿执行作用域链向上查找。

## 3. 新增端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/PUT/DELETE | `/service/runtime/executions/{id}/variables/{name}` | 执行变量读写删 |
| DELETE | `/service/runtime/executions/{id}/variables` | 清空执行变量 |
| GET | `/service/runtime/executions/{id}/variables/{name}/data` | 执行变量原始值 |
| PUT | `/service/runtime/process-instances/{id}/variables` | 批量创建/更新实例变量 |
| DELETE | `/service/runtime/process-instances/{id}/variables` | 清空实例变量 |
| GET | `/service/runtime/process-instances/{id}/variables/{name}/data` | 实例变量原始值 |
| DELETE | `/service/runtime/tasks/{id}/variables` | 清空任务局部变量 |
| GET | `/service/runtime/tasks/{id}/variables/{name}/data` | 任务变量原始值 |
| GET | `/service/history/historic-variable-instances/{id}/data` | 历史变量原始值 |
| GET | `/service/history/historic-process-instances/{id}/variables/{name}/data` | 实例历史变量原始值 |
| GET | `/service/history/historic-task-instances/{id}/variables/{name}/data` | 历史任务变量原始值 |
| GET | `/service/history/historic-detail/{id}/data` | 历史明细原始值 |
| POST | `/service/history/historic-process-instances/{id}/comments` | 历史实例添加评论 |
| DELETE | `/service/history/historic-process-instances/{id}/comments/{commentId}` | 历史实例删除评论 |

批量更新请求体接受数组或对象：

~~~json
[
  {"name": "amount", "type": "long", "value": 100},
  {"name": "approved", "type": "boolean", "value": true}
]
~~~

成功返回 200 与已更新变量列表；空体、非法 JSON、空数组返回 400。

## 4. 变量数据端点

- 响应 `Content-Type: application/octet-stream`。
- 字符串变量返回 UTF-8 字节；`[]byte` 原样返回。
- 数值、布尔、对象等非文本类型返回 400（`REST-0131`）。
- 变量不存在或不属于当前租户返回 404。

## 5. 历史查询语义

- `GetHistoricVariableByName` 在同一实例的多个作用域中取 `lastUpdatedTime` 最新者。
- `GetHistoricTaskVariableByName` 取任务维度最新变量；任务不存在返回 404。
- 历史实例评论创建复用 `AddProcessComment`，同时校验历史实例存在与租户。
- 评论删除校验评论所属实例与路径一致，避免跨实例删除。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 变量名空 | 400 | `ENGINE-1103` |
| 变量不存在 | 404 | `ENGINE-1104` |
| 执行不存在 | 404 | `ENGINE-0405` |
| 实例/明细不存在 | 404 | `ENGINE-0404` |
| 批量变量请求体非法 | 400 | `REST-0118` |
| 非文本变量下载 | 400 | `REST-0131` |

## 7. 限制

1. 二进制变量上传（multipart `file`）尚未实现，仅支持 JSON 变量。
2. `variables-async` 异步变量端点未实现。
3. 变量数据端点只支持字符串与字节切片，其他类型建议走 JSON 变量端点。
4. 执行变量读取包含继承值，删除只删除执行本地值。
