# 020 用户信息与头像

> 文档编号：002-020  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；011 REST API 与兼容契约

## 1. 背景

Flowable IDM 允许为用户保存任意键值信息（工号、部门、职位等）与头像。此前身份模块只有用户/组/成员关系与密码，缺少：

- 用户信息键值增删改查。
- 用户头像上传与下载。

本期补齐 7 个端点，并把用户信息/头像纳入引擎状态快照。

## 2. 引擎 API

`IdentityService` 新增：

| 方法 | 说明 |
| --- | --- |
| `GetUserInfo(ctx, userID)` | 用户信息映射 |
| `GetUserInfoValue(ctx, userID, key)` | 单个信息值 |
| `SetUserInfo(ctx, userID, key, value)` | 创建或更新 |
| `DeleteUserInfo(ctx, userID, key)` | 删除信息 |
| `GetUserPicture(ctx, userID)` | 头像数据与 MIME |
| `SetUserPicture(ctx, userID, data, mimeType)` | 设置头像 |

规则：

- 用户不存在返回 404。
- 信息键为空返回 400。
- 头像为空返回 400；MIME 为空默认 `image/jpeg`。
- 删除用户时同步删除其信息与头像。

## 3. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/identity/users/{id}/info` | 信息列表 |
| POST | `/service/identity/users/{id}/info` | 创建信息 |
| GET | `/service/identity/users/{id}/info/{key}` | 信息详情 |
| PUT | `/service/identity/users/{id}/info/{key}` | 更新信息 |
| DELETE | `/service/identity/users/{id}/info/{key}` | 删除信息 |
| GET | `/service/identity/users/{id}/picture` | 读取头像 |
| PUT | `/service/identity/users/{id}/picture` | 上传头像（multipart） |

信息响应：

~~~json
{
  "key": "title",
  "value": "Engineer",
  "url": "/service/identity/users/alice/info/title"
}
~~~

- POST 成功 201；重复 key 返回 409。
- PUT 成功 200；请求体 key 与路径不一致返回 400；key 不存在返回 404。
- DELETE 成功 204；不存在返回 404。
- 头像 GET 返回原始字节与创建时的 MIME 类型。
- 头像 PUT 使用 `multipart/form-data`，文件字段任意名称，可选 `mimeType` 表单字段。

## 4. 持久化

- 用户信息存入 `state.UserInfo`（userID → key → value）。
- 用户头像存入 `state.UserPictures`（userID → 数据 + MIME）。
- JSON 状态快照新增 `userInfo`、`userPictures` 字段；命令回滚克隆时深拷贝。
- SQL 行映射暂未覆盖身份表，沿用现有 JSON 快照持久化。

## 5. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 用户信息不存在 | 404 | `ENGINE-1701` |
| 信息键为空 | 400 | `ENGINE-1702` |
| 用户头像不存在 | 404 | `ENGINE-1703` |
| 头像为空 | 400 | `ENGINE-1704` |
| 信息键重复 | 409 | `ENGINE-1705` |
| key 与路径不一致 | 400 | `ENGINE-1706` |
| 用户不存在 | 404 | `ENGINE-0404` |

## 6. 限制

1. 用户信息值仅支持字符串，不支持二进制或复杂对象。
2. 头像无大小上限（受全局 64MB 上传限制），仅保存单张。
3. 头像不支持删除端点，更新即覆盖。
4. 身份表未接入 `ACT_ID_*` 行映射，跨数据库迁移仍需 JSON 快照。

## 7. 测试

- `internal/engine/user_info_test.go`：信息增删改查、头像、默认 MIME、快照与克隆、删除用户清理。
- `internal/rest/user_info_test.go`：REST 增删改查、重复冲突、multipart 上传、错误路径。
