# 039 模型部署与部署去重

> 文档编号：002-039  
> 更新日期：2026-10-28  
> 对应计划：012 流程模型仓库；011 REST API 与兼容契约

## 1. 背景

Flowable 支持把设计器中的流程模型直接部署为流程定义，并支持部署去重（相同资源不产生新版本）。

本期补齐：

- `POST /service/repository/models/{id}/deployment`
- `POST /service/repository/deployments?enableDuplicateFiltering=true`

## 2. 模型部署

`POST /service/repository/models/{id}/deployment`

流程：

1. `GetModel` 读取模型，模型不存在 404。
2. `GetModelSource` 读取源码；无源码映射为 400（`REST-0150`）。
3. 源码为空/纯空白返回 400（`REST-0151`）。
4. 部署资源名：
   - 模型 Key 非空：`{key}.bpmn20.xml`
   - Key 为空：`model-{id}.bpmn20.xml`
5. 部署名使用模型名，租户使用模型租户。
6. 成功返回 201 + Deployment JSON；BPMN 校验错误原样透传。

## 3. 部署去重

`POST /service/repository/deployments?enableDuplicateFiltering=true`

判定条件（全部满足）：

- 同租户（请求解析后的 `tenantId`）；
- 资源名集合一致；
- 每个资源字节完全一致。

行为：

- 命中：返回 **200** + 现有 Deployment，不调用部署、不产生新版本。
- 未命中：正常部署，返回 201。
- 多个匹配时返回最新部署。
- 参数为 `false` 或缺失：保持原有行为，始终创建新部署。

## 4. 限制

1. 去重为“先查后部署”，非原子；高并发下仍可能重复。
2. 未自动回写模型的 `deploymentId`。
3. 资源名仅 trim Key，未做路径字符过滤。
4. 未实现 Flowable 的部署更新/删除资源等模型端操作。

## 5. 测试

- `internal/rest/repository_extra_test.go`：模型部署成功/404/空源码/非法 BPMN；去重命中 200、不同租户/资源/字节、false 与缺省。
- 覆盖率：`internal/rest` 90.6%。
