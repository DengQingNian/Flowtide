# 051 执行监听器

> 文档编号：002-051
> 更新日期：2026-10-28
> 对应计划：006 流程执行引擎 PVM 设计；050 任务监听器

## 1. 背景

Flowable 允许在流程与流程节点上配置执行监听器，在 start/end 事件执行自定义逻辑。此前解析器忽略 `executionListener`。

本期实现流程级与活动级 start/end 事件的安全子集，监听器在命令事务内同步执行，失败即整体回滚。

## 2. BPMN 配置

~~~xml
<process id="p" isExecutable="true">
  <extensionElements>
    <flowable:executionListener event="start" class="processStart"/>
    <flowable:executionListener event="end" delegateExpression="processEnd"/>
  </extensionElements>

  <userTask id="task">
    <extensionElements>
      <!-- event 缺省为 start -->
      <flowable:executionListener class="taskStart"/>
      <flowable:executionListener event="end" delegateExpression="taskEnd"/>
    </extensionElements>
  </userTask>
</process>
~~~

- `process` 与全部 flow node（含 subProcess）均支持 `extensionElements/executionListener`。
- 兼容 `flowable:`、`activiti:` 与无前缀元素/属性。
- `event` 仅支持 `start`/`end`，缺省为 `start`，大小写不敏感；其他事件不会被触发。
- 实现方式：`class` 或 `delegateExpression` 作为注册名；二者同时存在时优先 `delegateExpression`。
- `expression` 暂不支持，触发时返回 400（`ENGINE-1942`）。

## 3. Go 注册

~~~go
engine.RegisterExecutionListener("taskStart", func(ctx context.Context, execution *engine.Execution) error {
    execution.SetVariable("startedBy", "listener")
    return nil
})
~~~

- 监听器类型定义在 `internal/engine`：`type ExecutionListener func(ctx context.Context, execution *Execution) error`。
- `Execution` 提供 `GetVariable`/`SetVariable`/`SetVariableLocal`/`ProcessInstanceID`/`ActivityID`。
- 监听器写入的变量立即对后续节点可见，并随命令一起提交/回滚。
- `api` 被 `internal/engine` 依赖，若在 `api` 中声明监听器类型会引用 `*engine.Execution` 并形成循环依赖，因此注册方法放在 `*Engine` 上（与 `RegisterDelegate` 一致），未加入 `api.RuntimeService` 接口。

## 4. 执行时机

| 范围 | 事件 | 时机 |
| --- | --- | --- |
| 流程 | start | 实例、根执行与历史实例创建后，进入开始事件前 |
| 流程 | end | 实例标记结束、清理任务/作业前 |
| 活动 | start | 历史活动开始记录后、节点逻辑执行前 |
| 活动 | end | 历史活动结束记录后、出线处理前 |

- 同一范围的监听器按 BPMN 中定义顺序执行。
- 活动 start 在历史级别不足时仍执行；活动 end 依赖历史活动记录反查活动定义，历史级别低于 `activity` 时不触发（安全跳过，不 panic）。
- 结束监听器拿到的 `ActivityID` 为刚结束的活动 ID，即使执行已离开该节点。

## 5. 错误与回滚

| 场景 | 错误码 | HTTP |
| --- | --- | --- |
| 缺少 class/delegateExpression | `ENGINE-1940` | 400 |
| 监听器未注册 | `ENGINE-1941` | 400 |
| 使用 expression | `ENGINE-1942` | 400 |
| 监听器返回错误 | `ENGINE-1943` | 500 |

- 监听器错误通过命令上下文汇聚，由 `execute` 统一回滚到命令开始前的状态。
- 启动阶段失败：不产生实例；完成用户任务失败：任务保留、实例保持运行。

## 6. 限制

1. 仅支持 start/end 事件，不支持 take 等其他 Flowable 事件。
2. 不支持表达式监听器与 Java 类加载；`class` 仅作为注册名。
3. 活动 end 监听器依赖历史活动记录，历史级别低于 `activity` 时不触发。
4. 监听器同步执行且持有引擎命令锁，不能在监听器内调用需要加锁的引擎 API（如启动流程）；通过 `Execution` 读写变量是安全的。
5. `DeleteProcessInstance` 不触发流程 end 监听器。
6. 不记录监听器执行历史。
