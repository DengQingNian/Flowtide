# 021 历史查询补充与管理属性

> 文档编号：002-021  
> 更新日期：2026-10-28  
> 对应计划：010 历史、事件与审计；011 REST API 与兼容契约

## 1. 背景

本期补齐两类能力：

- 历史变量与历史变量明细的 POST 组合查询。
- 管理端自定义引擎属性的创建、更新与删除。

## 2. 历史查询端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/service/query/historic-variable-instances` | 历史变量查询 |
| POST | `/service/query/historic-detail` | 历史变量明细查询 |

### 2.1 历史变量

支持字段：

`processInstanceId`、`executionId`、`taskId`、`variableName`/`name`、`variableNameLike`/`nameLike`、`variableType`/`type`、`sort`、`order`、`start`、`size`。

排序字段：`id`、`name`、`type`、`createTime`、`lastUpdatedTime`。

### 2.2 历史明细

支持字段：

`processInstanceId`、`executionId`、`taskId`、`activityInstanceId`/`activityId`、`variableName`/`name`、`variableNameLike`/`nameLike`、`variableType`/`type`、`timeAfter`、`timeBefore`、分页与排序。

排序字段：`id`、`name`、`variableType`、`time`。

### 2.3 租户

- 请求带租户时，通过历史实例索引过滤变量/明细。
- 独立任务变量没有实例 ID，不做租户过滤。
- 时间字段非法、排序非法、分页非法均返回 400。

## 3. 管理属性

### 3.1 引擎 API

`ManagementService` 新增：

| 方法 | 说明 |
| --- | --- |
| `CreateProperty(ctx, name, value)` | 创建自定义属性 |
| `UpdateProperty(ctx, name, value)` | 更新自定义属性 |
| `DeleteProperty(ctx, name)` | 删除自定义属性 |

规则：

- 内置属性（`schema.version`、`schema.history`、`next.dbid`、`engine.version`、`historyLevel`、`tenantId` 等）只读：
  - 创建返回 409。
  - 更新/删除返回 400。
- 自定义属性重复创建返回 409；更新/删除不存在返回 404。
- 属性名空白返回 400。

### 3.2 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/management/engine-properties` | 已有，返回内置+自定义 |
| POST | `/service/management/engine-properties` | 创建，201 |
| PUT | `/service/management/engine-properties/{name}` | 更新，200 |
| DELETE | `/service/management/engine-properties/{name}` | 删除，204 |

请求体：

~~~json
{"name": "feature.checkout", "value": "on"}
~~~

PUT 可省略 `name`；提供时必须与路径一致，否则 400。

## 4. 持久化

- 自定义属性存入 `state.Properties`。
- JSON 快照新增 `properties` 字段，命令回滚时深拷贝。
- SQL 行映射新增 `ACT_GE_PROPERTY`：
  - 导出仅写自定义属性。
  - 导入时忽略 `schema.version` 等内置 Schema 属性，避免覆盖内置值。

## 5. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 属性名空 | 400 | `ENGINE-1801` |
| 属性已存在 | 409 | `ENGINE-1802` |
| 内置属性不可修改 | 400 | `ENGINE-1803` |
| 属性不存在 | 404 | `ENGINE-1804` |
| 请求体名称与路径不一致 | 400 | `ENGINE-1805` |
| 历史查询参数非法 | 400 | `REST-0120`/`REST-0121`/`REST-0122`/`REST-0123` |

## 6. 限制

1. 历史变量/明细查询不支持按变量值过滤。
2. 独立任务历史变量不做租户过滤。
3. 自定义属性仅字符串值。
4. 内置属性由运行配置推导，不落库。
