# 007 真实数据库集成指南

> 文档编号：002-007  
> 更新日期：2026-10-28  
> 状态：集成测试入口已就绪；默认跳过，需驱动与 DSN

## 1. 目的

当前单元测试使用 SQL 测试替身。本文说明如何用真实 PostgreSQL/MySQL 验证：

- 41 张 `ACT_*` DDL 能否执行；
- `sqlstate` 能否保存/读取引擎快照；
- 后续按表仓储的读写行为。

## 2. 前置条件

1. 可用的 PostgreSQL 或 MySQL 实例（建议一次性/临时库）。
2. 在 `go.mod` 中加入驱动并注册：
   - PostgreSQL：`github.com/jackc/pgx/v5/stdlib`
   - MySQL：`github.com/go-sql-driver/mysql`
3. 设置环境变量：

~~~bash
export FLOWABLE_TEST_DRIVER=pgx
export FLOWABLE_TEST_DSN='postgres://user:pass@127.0.0.1:5432/flowable_test?sslmode=disable'
export FLOWABLE_TEST_DIALECT=postgres
~~~

MySQL 示例：

~~~bash
export FLOWABLE_TEST_DRIVER=mysql
export FLOWABLE_TEST_DSN='user:pass@tcp(127.0.0.1:3306)/flowable_test'
export FLOWABLE_TEST_DIALECT=mysql
~~~

## 3. 运行

~~~bash
go test ./internal/persistence/flowable -run TestIntegrationSQL -v
~~~

行为：

1. 未设置驱动/DSN 时 **跳过**。
2. 驱动未注册时 **跳过**（提示注册驱动）。
3. 连接成功后执行内置 DDL。
4. 使用 `sqlstate` 写入并读回 `integration-state`。

> 测试会向目标库执行建表语句，请使用专用测试库。

## 5. 当前限制

- 仓库内未直接依赖数据库驱动，集成测试需要使用者自行添加。
- 无自动清理；DDL 使用 `CREATE TABLE`（非 IF NOT EXISTS），重复运行需重建库。
- MySQL 时间/布尔类型差异尚未做集成断言。
