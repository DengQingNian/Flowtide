## 2. 已实现能力

### 2.1 BPMN 模型与解析

- 安全 XML 解码：命名空间、DTD 拒绝、深度/大小限制、ZIP 路径穿越防护。
- 元素：start/end、userTask、serviceTask、scriptTask、manualTask、callActivity、subProcess、adHocSubProcess、event subProcess、boundaryEvent、intermediateCatch/ThrowEvent、exclusive/parallel/inclusive/eventBased gateway、sequenceFlow、association。
- 扩展：message/signal/error 定义、timer、conditional 条件事件、multiInstance、in/out 参数、compensation、asyncBefore/asyncAfter、formKey、candidateUsers/Groups。
- 元素类型与关联校验；部署期错误码。

### 2.2 运行时

- 命令 + 事务级回滚；Agenda 操作循环；执行树与作用域。
- 用户任务：创建、签收、完成、委派/处理、候选用户/组、查询、变量、create/complete 任务监听器。
- 服务任务：Go 委托注册表、delegateExpression、表达式结果变量。
- 脚本任务：expression/juel/javascript 表达式子集；Groovy/Starlark 明确拒绝。
- 网关：排他、并行、包容、事件网关。
- 链接事件：中间抛出/捕获、同名跳转、捕获直通。
- 条件事件：中断/非中断边界、中间捕获、变量变化触发、显式求值。
- 动态注入：实例内独立用户任务，不影响主流程。
- 执行动作：定向消息/信号投递、信号广播、无事件等待触发。
- Ad-hoc 子流程：并行/串行激活、完成条件、提前取消。
- 子流程：嵌入式、嵌套、内部并行汇聚。
- 多实例：并行/串行、集合/基数、完成条件、提前取消、服务任务。
- 调用活动：变量继承、in/out 映射、深度限制、父子恢复。
- 事件：消息/信号启动、中间捕获、边界消息/信号、事件子流程、事件网关。
- 定时器：边界、启动、中间捕获；ISO-8601 首次触发。
- 错误：错误结束、错误边界、作用域传播、未捕获失败。
- 补偿：补偿边界、关联处理器、逆序执行（服务/手动）。
- 异步：asyncBefore/asyncAfter 作业、恢复、跳过标记。
- 挂起/激活：定义、实例、实例联动、任务/作业限制。
- 迁移：活动映射、任务重映射、租户/类型/作业/订阅校验。
- 身份：用户、组、成员关系、候选组查询。
- 历史：流程、活动、任务、变量；audit 级别。

## 4. 剩余差距

### 4.1 P0：生产可用性

| 差距 | 影响 | 建议 |
| --- | --- | --- |
| 按表仓储尚未接入 MySQL 服务模式 | 状态仍为 JSON Blob，无法 SQL 查询执行/任务 | MySQL 快照接入已实现，后续补齐真实事务适配与外键顺序 |
| mTLS 与全量权限专项审计未完成 | 已绑定认证租户仍不能替代全部安全验收 | mTLS、权限矩阵及负向回放 |
| 无集群作业抢占与重试/死信 | 只能单节点运行 | 作业表加锁、重试、死信、管理 API |
| 方法级端点对照仍存在官方缺失项 | 客户端兼容不足 | 补齐 CMMN、BKM/决策服务与按表仓储 |

## 5. 已知限制

1. **脚本**：仅表达式子集，不支持完整 JS 语句、Groovy、Starlark；生产应限制脚本任务或引入沙箱引擎。
2. **持久化**：文件与 MySQL JSON 快照均为过渡方案，全量写入，单快照不支持多进程并发与大数据量。
3. **集群**：无多节点锁、作业抢占、缓存失效。
4. **安全**：已有 Basic/静态 Bearer、PBKDF2、RBAC、租户隔离与 JWT/JWKS（RS256/HS256）；mTLS 未实现。
5. **历史**：已记录评论、附件、身份链接、变量明细；full 级别的异步历史与定期清理未实现。
6. **REST**：覆盖核心路径，不是 Flowable 全量契约；未做 OpenAPI 契约测试。
7. **执行语义**：事件子流程/补偿/事务/迁移做了简化，边界场景需与参考实现对比验证。
8. **管理表数据**：来自内存快照而非实时 SQL 查询，二进制列以 Base64 输出。

## 6. 下一阶段建议

1. **持久化层**：把行仓储接入真实数据库，补齐事务边界、连接池与慢查询指标。
2. **作业体系**：集群抢占、锁过期、幂等和外部工作项。
3. **REST 扩展**：按官方 OpenAPI 生成路由清单，以方法级清单补齐缺失项并验证模式、错误、分页与副作用。
4. **BPMN 补全**：完整定时器周期、动态 BPMN 与已有子集的 Java 对照。
5. **安全**：既有 JWT/JWKS 的全量权限审计、mTLS 与管理端点授权。
6. **兼容性**：移植参考仓库 BPMN 夹具，建立执行路径黄金对比。
