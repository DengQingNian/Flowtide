# v0.1.1 模块发布校验

日期：2026-11-01。

## 发布范围

本版提供根包完整嵌入 SDK、workflow 门面、HTTP Handler、作业生命周期和 MySQL 结构检查入口。Go 最低版本为 1.27。业务能力来自 `8a0f2e4`，本次发布修复只调整文档文件名与对应链接。

## 模块打包问题与修复

首次下载校验发现，重构计划目录中的八个 Markdown 文件名含顿号 `、`，不符合 Go 模块 zip 的文件名规则。标准校验服务拒绝生成该版本的模块包。

先使用 `golang.org/x/mod/zip.CreateFromVCS` 对原提交复现失败，再将这八个文件名中的顿号替换为连字符，并同步审计文档中的相对链接。保留中文标题、正文与目录组织。

发布时必须重新验证标准模块下载及校验和，不能通过关闭校验服务或本地 replace 绕过文件名问题。

## 已知测试限制

发布前执行 Windows 平台的 `go test ./... -count=1`。根包、API、引擎、REST、持久化及其他包通过；workflow 中既有 `TestSchedulerTriggerFunctions` 因固定假时钟与真实计时混用失败。本次未修改调度器实现，不将全仓测试记录为通过。
