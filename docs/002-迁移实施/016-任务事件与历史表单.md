# 016 任务事件与历史表单

> 文档编号：002-016  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；010 历史、事件与审计

## 1. 背景

Flowable 的任务详情页需要展示任务生命周期事件（创建、签收、委派、完成、删除等），历史任务详情页还需要读取表单定义与字段值。本期补齐：

- 任务事件列表/详情/删除（3 个端点）。
- 历史任务表单（1 个端点）。
- 单条历史实例评论（1 个端点）。
- 历史任务 DTO 增加 `formKey`。

## 2. 任务事件

`TaskService` 新增：

| 方法 | 说明 |
| --- | --- |
| `ListTaskEvents(ctx, taskID)` | 任务事件列表 |
| `GetTaskEvent(ctx, taskID, eventID)` | 单个事件 |
| `DeleteTaskEvent(ctx, taskID, eventID)` | 删除事件 |

数据来源为任务生命周期日志（`ACT_HI_TSK_LOG` 映射）：

| 字段 | 说明 |
| --- | --- |
| `id` | 事件 ID |
| `action` | create/claim/delegate/complete/update/delete |
| `timestamp` | 发生时间 |
| `userId` | 操作人 |
| `taskId` | 任务 ID |
| `executionId` | 执行 ID |
| `processInstanceId` | 实例 ID |
| `processDefinitionId` | 定义 ID |
| `tenantId` | 租户 |
| `data` | 附加数据（如删除原因） |

访问规则：

- 运行时任务按任务租户校验。
- 已完成任务回退到历史任务所属实例校验。
- 删除事件要求任务仍在运行时存在；任务完成后删除返回 404。
- 列表按时间与 ID 稳定排序。

## 3. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/runtime/tasks/{id}/events` | 事件列表 |
| GET | `/service/runtime/tasks/{id}/events/{eventId}` | 事件详情 |
| DELETE | `/service/runtime/tasks/{id}/events/{eventId}` | 删除事件 |
| GET | `/service/history/historic-task-instances/{id}/form` | 历史任务表单 |
| GET | `/service/history/historic-process-instances/{id}/comments/{commentId}` | 单条历史评论 |

- 事件 ID 非整数返回 400（`REST-0132`）。
- 事件不存在或不属于该任务返回 404。

## 4. 历史任务表单

`HistoryService` 新增 `GetHistoricTaskFormData(ctx, taskID)`。

流程：

1. 查询历史任务，`formKey` 为空返回 400。
2. 通过历史任务所属实例找到流程定义与用户任务。
3. 用历史变量（实例级 + 任务级）填充表单字段当前值。
4. 返回 `{formKey, formProperties}`。

- 独立任务或实例已删除时，仅返回 `formKey`，字段列表为空。
- 实例/定义/任务节点不存在时同样降级返回 `formKey`。
- 缺失历史任务返回 404。

## 5. 单条历史评论

`GET /service/history/historic-process-instances/{id}/comments/{commentId}`

- 校验历史实例存在与租户。
- 校验评论所属实例与路径一致，避免跨实例读取。
- 不匹配或不存在返回 404。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 任务事件不存在 | 404 | `ENGINE-1401` |
| 任务无表单 | 400 | `ENGINE-1402` |
| 事件 ID 非整数 | 400 | `REST-0132` |
| 任务/实例不存在 | 404 | `ENGINE-0805`/`ENGINE-0404` |

## 7. 限制

1. 任务事件来自任务日志，不是独立的运行事件表；日志级别低于 task 时为空。
2. 历史任务表单不计算表单字段的动态默认值，仅使用历史变量。
3. 事件删除不会写入审计日志。
4. 任务事件不支持分页，按任务全量返回。
