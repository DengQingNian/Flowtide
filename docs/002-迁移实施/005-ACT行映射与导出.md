# 005 ACT_* 行映射与导出

> 文档编号：002-005  
> 更新日期：2026-10-28  
> 状态：首批三张表已可导出；按表读写仍待接入引擎

## 1. 目标

把引擎内存状态转换为 Flowable `ACT_*` 行，为按表仓储提供**列级映射、SQL 生成与导出**能力。

本轮覆盖：

| 表 | 说明 |
| --- | --- |
| `ACT_RE_DEPLOYMENT` | 部署 |
| `ACT_RE_PROCDEF` | 流程定义 |
| `ACT_GE_BYTEARRAY` | 部署资源内容 |

## 2. 行模型

~~~go
row, err := flowablerow.NewRow("ACT_GE_BYTEARRAY")
err = row.Set("ID_", "ba-...")
err = row.Set("BYTES_", data)
query, args, err := row.InsertSQL("postgres")
~~~

- 表和列均为白名单，未知表/列返回 `ROW-0001/0002`。
- `Args()` 严格按 DDL 列顺序输出。
- `InsertSQL` 支持 MySQL `?` 与 PostgreSQL `$n`。
- `DeleteSQL` 仅按 `ID_` 删除。

### 2.1 导出

~~~go
rows, err := engine.ExportRows(ctx)
~~~

- 每部署 1 行 `ACT_RE_DEPLOYMENT`。
- 每资源 1 行 `ACT_GE_BYTEARRAY`，ID 为 `ba-` + `sha256(deploymentID|resourceName)` 前 32 位。
- 每流程定义 1 行 `ACT_RE_PROCDEF`，挂起状态映射为 `SUSPENSION_STATE_=2`。
- 输出按表名、ID 排序，保证可重复。

## 3. 与引擎的关系

当前：

- 引擎仍通过 `Store` 保存整体 JSON 快照。
- `ExportRows` 是**只读导出**，不参与运行时写入。
- 可用于对账、离线导入、按表仓储的种子数据。

尚未实现：

- 从行恢复引擎状态。
- 行级事务与 `REV_` 乐观锁。
- `ACT_RU_*`、`ACT_HI_*`、`ACT_ID_*` 行映射。
