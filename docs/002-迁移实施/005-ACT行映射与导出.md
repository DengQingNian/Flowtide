# 005 ACT_* 行映射与导出

> 文档编号：002-005  
> 更新日期：2026-10-28  
> 状态：13 张表可导出；仓库/运行时/死信可恢复，历史仅导出

## 1. 目标

把引擎内存状态转换为 Flowable `ACT_*` 行，为按表仓储提供**列级映射、SQL 生成与导出**能力。

本轮覆盖：

| 表 | 说明 |
| --- | --- |
| `ACT_RE_DEPLOYMENT` | 部署 |
| `ACT_RE_PROCDEF` | 流程定义 |
| `ACT_GE_BYTEARRAY` | 部署资源内容 |
| `ACT_RU_EXECUTION` | 运行中执行 |
| `ACT_RU_TASK` | 运行中任务 |
| `ACT_RU_VARIABLE` | 运行中变量 |
| `ACT_RU_JOB` | 运行中作业 |
| `ACT_RU_EVENT_SUBSCR` | 事件订阅 |
| `ACT_RU_DEADLETTER_JOB` | 死信作业 |
| `ACT_HI_PROCINST` | 历史流程实例 |
| `ACT_HI_ACTINST` | 历史活动 |
| `ACT_HI_TASKINST` | 历史任务 |
| `ACT_HI_VARINST` | 历史变量 |

### 1.1 运行时行

~~~go
rows, err := engine.ExportRuntimeRows(ctx)
~~~

- 执行行包含实例、父执行、定义、活动、作用域/并发/挂起状态。
- 任务行包含执行、定义、任务 Key、处理人、到期时间、表单 Key。
- 变量行按类型写入 `LONG_`/`DOUBLE_`/`TEXT_`：
  - 字符串 → `TEXT_`
  - 布尔/整数 → `LONG_`
  - 浮点 → `DOUBLE_`
  - 其他 → JSON 文本
- 变量 ID 为 `var-` + SHA-256(执行|任务|名称) 前 32 位。
- 作业行保留原始类型、重试、异常、到期时间与重复配置（JSON）。
- 订阅行保留事件类型/名称、执行、作用域类型与边界/事件子流程元数据。
- 死信行保留原作业类型、异常、到期时间与重复配置。

## 2. 行模型

~~~go
row, err := flowablerow.NewRow("ACT_GE_BYTEARRAY")
err = row.Set("ID_", "ba-...")
err = row.Set("BYTES_", data)
query, args, err := row.InsertSQL("postgres")
~~~

- 表和列均为白名单，未知表/列返回 `ROW-0001/0002`。
- `Args()` 严格按 DDL 列顺序输出。
- `InsertSQL` 支持 MySQL `?` 与 PostgreSQL `$n`。
- `DeleteSQL` 仅按 `ID_` 删除。

### 2.1 导出

~~~go
rows, err := engine.ExportRows(ctx)
~~~

- 每部署 1 行 `ACT_RE_DEPLOYMENT`。
- 每资源 1 行 `ACT_GE_BYTEARRAY`，ID 为 `ba-` + `sha256(deploymentID|resourceName)` 前 32 位。
- 每流程定义 1 行 `ACT_RE_PROCDEF`，挂起状态映射为 `SUSPENSION_STATE_=2`。
- 输出按表名、ID 排序，保证可重复。

## 3. 行恢复

~~~go
snapshot, err := flowablerow.DecodeRows(rows)
err := engine.ImportRows(ctx, rows)
~~~

- `DecodeRows` 恢复部署、资源与流程定义，校验部署/资源引用。
- `ImportRows` 重新解析 BPMN XML，重建部署、定义、启动订阅与定时启动作业。
- 重复导入会先清理同定义的启动订阅/定时作业，避免重复触发。
- 仅恢复仓库数据，不恢复运行中实例、任务、历史。
### 3.1 运行时恢复

~~~go
err := engine.ImportRuntimeRows(ctx, runtimeRows)
~~~

- 从执行行重建流程实例与执行树，选择无父执行的节点作为根执行。
- 从任务行重建用户任务与到期时间。
- 从变量行恢复执行变量与任务局部变量，支持 string/boolean/long/double/json/null。
- 任务所在执行标记为等待状态。
- 作业与事件订阅按行恢复，支持定时器、异步作业、消息/信号捕获。

已恢复：事件订阅、定时/异步作业、死信作业。

历史行目前只导出，可通过 `ExportHistoricRows` 获取 `ACT_HI_*` 行，尚未反向恢复。

当前：

- 引擎仍通过 `Store` 保存整体 JSON 快照。
- `ExportRows`/`ImportRows` 可做对账、离线导入、按表仓储的种子数据。
