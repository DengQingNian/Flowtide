# 027 流程定义模型与制品端点

> 文档编号：002-027  
> 更新日期：2026-10-28  
> 对应计划：005 BPMN 模型、XML 解析与部署校验；011 REST API 与兼容契约

## 1. 背景

Flowable 提供流程定义模型与关联制品查询：

- `GET /repository/process-definitions/{id}/model`
- `GET /repository/process-definitions/{id}/decisions`
- `GET /repository/process-definitions/{id}/decision-tables`
- `GET /repository/process-definitions/{id}/form-definitions`

本期补齐 4 个端点。流程模型返回精简 DTO；决策/表单制品在未集成对应引擎时返回空数组。

## 2. 模型端点

`GET /service/repository/process-definitions/{id}/model`

响应结构：

~~~json
{
  "id": "leave:1:abc",
  "name": "Leave",
  "processes": [
    {
      "id": "leave",
      "name": "Leave",
      "documentation": "",
      "executable": true,
      "flowElements": [
        {"id": "start", "name": "Start", "type": "startEvent"},
        {"id": "flow", "name": "", "type": "sequenceFlow", "sourceRef": "start", "targetRef": "task"},
        {"id": "task", "name": "Approve", "type": "userTask", "assignee": "alice", "formKey": "leaveForm"}
      ]
    }
  ],
  "messages": [{"id": "msg1", "name": "Message"}],
  "signals": [{"id": "sig1", "name": "Signal"}],
  "errors": [{"id": "err1", "errorCode": "E1"}]
}
~~~

规则：

- 元素严格按 `Process.Order` 输出。
- `sequenceFlow` 额外输出 `sourceRef`/`targetRef`。
- `userTask` 额外输出 `assignee`、`formKey`、`candidateUsers`、`candidateGroups`。
- 空集合输出 `[]`，不输出 `null`。
- 定义不存在返回 404。

## 3. 制品端点

| 方法 | 路径 | 当前返回 |
| --- | --- | --- |
| GET | `.../{id}/decisions` | `[]` |
| GET | `.../{id}/decision-tables` | `[]` |
| GET | `.../{id}/form-definitions` | `[]` |

- 先校验流程定义存在，不存在返回 404。
- 当前引擎未集成 DMN 决策引擎与 Form 引擎，因此返回空数组而非报错，保证客户端兼容。

## 4. 限制

1. 模型 DTO 为精简结构，不等同于 Flowable 完整 `BpmnModel` JSON（不含图形、扩展属性、监听器、多实例等全部字段）。
2. 决策/决策表/表单制品未实现，始终为空。
3. 未提供模型 JSON 的写入/更新端点。
