## 1. 本阶段目标

把规划中的 BPMN 内核落成一个**可编译、可测试、可运行**的纯 Go 垂直切片，验证以下链路：

~~~text
BPMN XML → 模型解析 → 部署 → 启动实例 → 执行树推进 → 用户任务等待
→ 完成任务 → 网关/服务任务 → 结束 → 历史记录 → REST 查询
~~~

本阶段不追求功能完整，而是建立可持续扩展的骨架：命令/回滚、执行树、议程、行为分发、历史、REST 都按最终形态预留接口。

## 4. 代码结构

~~~text
api/                     公共接口与 DTO
bpmn/model/              BPMN 模型
internal/bpmn/xml/       XML 解码与解析
internal/expr/           UEL 子集
internal/clock/          可注入时钟
internal/idgen/          UUIDv7
internal/engine/         状态、命令、议程、运行时、任务、历史、仓储
internal/rest/           HTTP API
cmd/flowable-server/     服务端入口
~~~

关键设计：

- **命令即事务**：`Engine.execute» 在锁内执行命令，失败用 `cloneState» 回滚。
- **执行树 + 议程**：行为不递归，统一调度 `continueOperation» / `takeOutgoingOperation»。
- **变量作用域**：执行树向上查找，写入最近已存在作用域或根执行。
- **历史级别**：支持 none/instance/task/activity/audit/full 配置，当前实现 instance/activity/task 的主要表。
- **REST 与服务解耦**：`internal/rest» 只依赖 `api.Engine»。

## 5. 运行方式

~~~bash
# 构建
go build -o bin/flowable-server ./cmd/flowable-server

# 启动（默认 :8080）
./bin/flowable-server -addr :8080 -history audit -state ./data/engine.json -jobs-interval 1s

# 部署
curl -X POST 'http://localhost:8080/service/repository/deployments?deploymentName=demo' \
  -H 'Content-Type: application/xml' \
  --data-binary @process.bpmn20.xml

# 启动实例
curl -X POST 'http://localhost:8080/service/runtime/process-instances' \
  -H 'Content-Type: application/json' \
  -d '{"processDefinitionKey":"demo","variables":[{"name":"initiator","value":"alice"}]}'

# 查询待办
curl 'http://localhost:8080/service/runtime/tasks?assignee=alice'

# 完成任务
curl -X POST 'http://localhost:8080/service/runtime/tasks/{taskId}' \
  -H 'Content-Type: application/json' \
  -d '{"action":"complete","userId":"alice"}'
~~~
