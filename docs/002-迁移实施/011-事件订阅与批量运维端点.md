# 011 事件订阅与批量运维端点

> 文档编号：002-011  
> 更新日期：2026-10-28  
> 对应计划：009 作业、定时器与异步执行；011 REST API 与兼容契约

## 1. 背景

运行时排障需要观察消息/信号订阅；任务详情页需要读取单条评论与附件；运维脚本需要批量清理实例；客户端下载流程定义需要原始资源端点。

本期补齐：

- 事件订阅列表与详情。
- 单条评论、单个附件读取。
- 任务参与者按用户/组分组查询。
- 运行中实例与历史实例批量删除。
- 流程定义原始资源下载。
- 修正运行中实例列表包含已结束实例的问题。

## 2. 事件订阅

`RuntimeService` 新增：

| 方法 | 说明 |
| --- | --- |
| `ListEventSubscriptions(ctx, processInstanceID)` | 查询订阅，空实例 ID 表示全部 |
| `GetEventSubscription(ctx, subscriptionID)` | 查询单条订阅 |

`api.EventSubscription` 字段：

~~~json
{
  "id": "sub-1",
  "url": "/service/runtime/event-subscriptions/sub-1",
  "eventType": "message",
  "eventName": "approvedMessage",
  "executionId": "exec-1",
  "processInstanceId": "pi-1",
  "activityId": "wait",
  "processDefinitionId": "def-1",
  "tenantId": "tenant-a",
  "created": "2026-10-28T01:02:03.000+08:00"
}
~~~

### 2.1 端点

| 方法 | 路径 |
| --- | --- |
| GET | `/service/runtime/event-subscriptions` |
| GET | `/service/runtime/event-subscriptions/{id}` |

列表支持查询参数：

`id`、`eventType`、`eventName`、`activityId`、`executionId`、`processInstanceId`、`processDefinitionId`、`withoutProcessInstanceId`、`withoutProcessDefinitionId`、`withoutTenantId`、`createdAfter`、`createdBefore`、`sort`、`order`、`start`、`size`。

排序字段：`id`、`created`、`executionId`、`processInstanceId`、`processDefinitionId`、`tenantId`。

租户隔离在引擎层完成：请求租户与订阅所属实例租户不一致时不可见，单条查询返回 404。

## 3. 单条评论与附件

`TaskService` 新增 `GetComment` 与 `GetAttachment`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/runtime/tasks/{id}/comments/{commentId}` | 读取评论 |
| GET | `/service/runtime/tasks/{id}/attachments/{attachmentId}` | 读取附件元数据 |
| GET | `/service/runtime/tasks/{id}/identitylinks/{family}` | family 为 `users` 或 `groups` |

- 评论/附件的 `taskId` 必须与路径任务一致，否则返回 404。
- 独立任务的评论/附件同样支持。
- 附件内容下载尚未实现，`content` 端点留待后续。

## 4. 批量删除

| 方法 | 路径 | 请求体 |
| --- | --- | --- |
| POST | `/service/runtime/process-instances/delete` | `{"processInstanceIds":["..."],"deleteReason":"..."}` |
| POST | `/service/history/historic-process-instances/delete` | `{"processInstanceIds":["..."]}` |

- 成功返回 204。
- `processInstanceIds` 为空返回 400。
- 任一 ID 不存在返回 404；已成功删除的实例不会回滚（逐实例事务）。
- 运行实例删除会写入历史结束信息，历史删除会清理活动、任务、变量、明细、身份链接、评论、附件与任务日志。

## 5. 原始资源下载

`GET /service/repository/process-definitions/{id}/resourcedata`

- 返回 BPMN 原始 XML。
- `Content-Type: application/octet-stream`。
- `Content-Disposition: attachment; filename="..."`，文件名取流程定义的资源名。
- 定义不存在返回 404。

## 6. 运行中实例语义修正

`ListProcessInstances` 此前包含已结束实例，导致：

- `/service/runtime/process-instances` 返回历史数据。
- 运行中实例指标偏大。
- 查询端点 `finished=false` 失效。

现在已结束实例只保留在历史中，运行中列表、指标与组合查询保持一致。

## 7. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 事件订阅不存在 | 404 | `ENGINE-0701` |
| 评论/附件不存在 | 404 | `ENGINE-0404` |
| 参与者类型非法 | 400 | `REST-0127` |
| 批量删除 ID 为空 | 400 | `REST-0128` |
| 排序非法 | 400 | `REST-0123` |
