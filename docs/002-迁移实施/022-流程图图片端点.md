# 022 流程图图片端点

> 文档编号：002-022  
> 更新日期：2026-10-28  
> 对应计划：005 BPMN 模型、XML 解析与部署校验；011 REST API 与兼容契约

## 1. 背景

Flowable 提供流程定义图片与运行实例流程图：

- `GET /repository/process-definitions/{id}/image`
- `GET /runtime/process-instances/{id}/diagram`

本期实现 BPMN DI 解析、SVG/PNG 渲染与运行态活动高亮，纯标准库、无第三方图形依赖。

## 2. 图形解析

新增 `internal/bpmn/diagram` 包：

| 类型 | 说明 |
| --- | --- |
| `Diagram` | 画布尺寸、图形节点、连线 |
| `Shape` | 元素的 BPMNShape 边界、名称、类型、标签区域 |
| `Edge` | 顺序流的折线点、名称、标签区域 |

解析规则：

- 从 BPMN XML 中读取 `BPMNDiagram/BPMNPlane`。
- `BPMNShape` 读取 `bpmnElement` 与 `omgdc:Bounds`。
- `BPMNEdge` 读取 `omgdi:waypoint` 列表。
- 名称与类型从解析后的 BPMN 模型补全。
- 画布尺寸取所有图形/连线/标签的最大范围并留 20px 边距。
- 无图形信息（无 DI 或无有效 Shape）返回 400。

## 3. 渲染

### 3.1 SVG

- 使用原生 SVG 元素：矩形、圆、菱形、折线、文本。
- 支持完整 Unicode 标签。
- 顺序流带箭头 marker，关联线使用虚线。
- 活动高亮填充 `#dbeafe`、描边 `#2563eb`。

### 3.2 PNG

- 纯标准库 `image/png` 输出。
- 2 倍超采样后盒式降采样，减少锯齿。
- 图形类型：事件（单/双圆）、网关（菱形）、任务（矩形）、调用活动、子流程、事务、文本注释、数据对象。
- 顺序流、虚线关联、箭头。
- 标签使用内置 4x6 笔画字体，**仅支持 ASCII**（小写自动转大写）。

### 3.3 内容协商

- 默认返回 `image/png`。
- 请求头 `Accept: image/svg+xml` 时返回 SVG。
- SVG 为扩展能力，Flowable 官方契约仍为 PNG。

## 4. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/repository/process-definitions/{id}/image` | 定义图片 |
| GET | `/service/runtime/process-instances/{id}/diagram` | 实例流程图（高亮当前活动） |

实例流程图通过 `ListActivityInstances` 收集当前活动 ID 进行高亮。

## 5. 限制

1. PNG 标签仅 ASCII；中文/其他 Unicode 标签只在 SVG 中展示。
2. 未渲染 BPMN 图标细节（定时器、消息、脚本等内部图形）。
3. 未渲染泳道/池（Lane/Pool）。
4. 未实现图片缓存；每次请求重新解析与渲染。
5. 大流程图受画布尺寸限制，未做分块或缩放参数。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| BPMN XML 解析失败 | 400 | `ENGINE-1901` |
| 缺少 DI/图形信息 | 400 | `ENGINE-1901` |
| 定义/实例不存在 | 404 | `ENGINE-0404` |
