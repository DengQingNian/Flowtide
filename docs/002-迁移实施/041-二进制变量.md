# 041 二进制变量

> 文档编号：002-041  
> 更新日期：2026-10-28  
> 对应计划：007 变量、表达式与脚本引擎；011 REST API 与兼容契约

## 1. 背景

Flowable 变量支持二进制类型（`binary`），通过 multipart 文件上传、通过 `/data` 端点下载原始字节。此前仅支持 JSON 变量，`[]byte` 变量虽可存储但没有上传入口。

本期补齐：

- 执行/实例/任务单变量 `PUT` 的 multipart 支持。
- 实例变量 `POST` 的 multipart 支持。
- 变量类型统一为 Flowable 的 `binary`。

## 2. 上传

端点（路径变量名优先）：

- `PUT /runtime/executions/{id}/variables/{name}`
- `PUT /runtime/process-instances/{id}/variables/{name}`
- `PUT /runtime/tasks/{id}/variables/{name}`
- `POST /runtime/process-instances/{id}/variables`

请求：

```
Content-Type: multipart/form-data
file=<二进制文件>
name=<变量名，仅 POST 或路径变量为空时需要>
```

- 文件字段任意名称，取第一个文件。
- 空文件返回 400（`REST-0144`）。
- 无法确定变量名返回 400（`REST-0145`）。
- 成功：执行变量 PUT 返回 200 + 变量 DTO；实例/任务 PUT 返回 204；实例 POST 返回 201。

## 3. 下载

现有端点：

- `GET /runtime/executions/{id}/variables/{name}/data`
- `GET /runtime/process-instances/{id}/variables/{name}/data`
- `GET /runtime/tasks/{id}/variables/{name}/data`
- `GET /history/.../variables/{name}/data`

返回 `application/octet-stream` 原始字节；非二进制/非字符串变量返回 400。

## 4. 表示

- 变量类型为 `binary`。
- 变量列表/详情 JSON 中值按 Go `[]byte` 编码为 Base64 字符串。
- 历史变量同样记录类型与值。

## 5. 限制

1. 未实现流式上传/下载，文件一次性读入内存，受全局 64MB 限制。
2. 批量变量端点（`PUT /variables`）仍只支持 JSON，不支持一次 multipart 多文件。
3. JSON 表示使用 Base64，客户端需自行解码；Flowable 原生对二进制变量通常返回 `null`/链接形式。
4. 未实现变量内容类型（MIME）元数据。
