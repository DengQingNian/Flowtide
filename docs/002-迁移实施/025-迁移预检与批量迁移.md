# 025 迁移预检与批量迁移

> 文档编号：002-025  
> 更新日期：2026-10-28  
> 对应计划：013 里程碑、排期与资源计划；011 REST API 与兼容契约

## 1. 背景

Flowable 迁移支持先校验再执行，并支持按流程定义批量迁移实例：

- `POST /runtime/process-instances/{id}/validate-migration`
- `POST /repository/process-definitions/{id}/migrate`
- `POST /repository/process-definitions/{id}/batch-migrate`

此前只有单实例迁移。本期补齐校验与批量入口。

## 2. 引擎 API

`RuntimeService` 新增 `ValidateMigration(ctx, req) ([]string, error)`。

实现：

- 将原迁移逻辑拆为“校验 + 计划”和“应用计划”。
- 校验返回消息列表，空列表表示可迁移。
- 校验不修改任何状态。
- 结构性错误（实例/目标定义不存在、租户不匹配、已结束、目标挂起）仍返回错误。
- 可迁移性问题返回消息：
  - 实例存在活动作业。
  - 实例存在事件订阅。
  - 实例没有可迁移执行。
  - 活动缺失或类型不兼容。
  - 目标任务活动不存在或类型不兼容。

`MigrateProcessInstance` 复用同一计划；存在校验消息时返回 400（`ENGINE-0650`）。

## 3. 端点

### 3.1 迁移预检

`POST /service/runtime/process-instances/{id}/validate-migration`

请求：

~~~json
{
  "targetProcessDefinitionId": "leave:2:abc",
  "activityMappings": {"oldTask": "newTask"}
}
~~~

响应：

~~~json
{"validationMessages": []}
~~~

- 缺少目标定义返回 400。
- 实例/目标不存在返回 404。
- 校验消息非空仍返回 200。

### 3.2 定义批量迁移

`POST /service/repository/process-definitions/{id}/migrate`
`POST /service/repository/process-definitions/{id}/batch-migrate`

请求：

~~~json
{
  "processInstanceIds": ["pi-1", "pi-2"],
  "activityMappings": {"oldTask": "newTask"}
}
~~~

- 路径中的定义 ID 作为目标定义。
- 同步逐个迁移，成功返回 204。
- 空列表返回 400；任一实例失败立即返回错误（已迁移实例不回滚）。

## 4. 限制

1. `batch-migrate` 为同步兼容实现，未创建 Flowable 批处理实体/分片。
2. 批量迁移为逐实例事务，失败时前面的实例保持已迁移状态。
3. 校验消息为纯文本，未提供机器可读错误码。
4. 预检只读取当前状态，不预留并发冲突检查。

## 5. 测试

- `internal/engine/migration_validate_test.go`：合法/非法预检、状态不变、作业阻断、缺失实例/目标。
- `internal/rest/migration_extra_test.go`：预检端点、定义迁移、批处理迁移、错误路径。
- 覆盖率：`internal/engine` 90.7%，`internal/rest` 90.3%。
