# 019 运行时变量实例查询

> 文档编号：002-019  
> 更新日期：2026-10-28  
> 对应计划：007 变量、表达式与脚本引擎；011 REST API 与兼容契约

## 1. 背景

Flowable 的变量实例（Variable Instance）以“变量 ID”标识运行时的单个变量，支持按实例、执行、任务、变量名查询，并可通过 `/data` 下载原始值。

此前变量只能按执行/实例/任务整体读取。本期补齐：

- 运行时变量实例列表。
- 变量实例 POST 组合查询。
- 变量实例原始值下载。

## 2. 引擎 API

`RuntimeService` 新增：

| 方法 | 说明 |
| --- | --- |
| `ListVariableInstances(ctx, filter)` | 按条件查询变量实例 |
| `GetVariableInstance(ctx, variableID)` | 按 ID 查询变量实例 |

`VariableInstanceFilter`：

| 字段 | 说明 |
| --- | --- |
| `ProcessInstanceID` | 流程实例 ID |
| `ExecutionID` | 执行 ID |
| `TaskID` | 任务 ID |
| `Name` | 变量名精确匹配 |
| `NameLike` | 变量名模糊匹配（忽略大小写与 `%`） |

`api.VariableInstance` 字段：`id`、`name`、`type`、`value`、`processInstanceId`、`executionId`、`taskId`、`scope`。

标识规则：

- 执行变量 ID = `hash(executionId, "", name)`。
- 任务变量 ID = `hash(executionId, taskId, name)`。
- 与 SQL 行导出共用同一算法（`var-<32 hex>`），保证导出/导入稳定。
- 作用域：执行变量为 `global`，任务局部变量为 `local`。

## 3. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/runtime/variable-instances` | 变量实例列表 |
| POST | `/service/query/variable-instances` | 组合查询 |
| GET | `/service/runtime/variable-instances/{id}/data` | 变量原始值 |

GET 参数：

`processInstanceId`、`executionId`、`taskId`、`variableName`/`name`、`variableNameLike`/`nameLike`、`sort`、`order`、`start`、`size`。

排序字段：`id`、`name`、`type`、`processInstanceId`、`executionId`、`taskId`。

POST 请求体示例：

~~~json
{
  "processInstanceId": "pi-1",
  "variableNameLike": "amount%",
  "sort": "name",
  "order": "asc",
  "start": 0,
  "size": 10
}
~~~

## 4. 数据端点

- 字符串返回 UTF-8 字节，`[]byte` 原样返回。
- 数值、布尔、对象等非文本类型返回 400（`REST-0131`）。
- 变量实例不存在或跨租户返回 404（`ENGINE-1601`）。

## 5. 语义与限制

- 仅返回未结束流程实例的变量；流程结束或实例删除后变量从运行态消失（历史变量仍可查）。
- 只枚举执行局部变量与任务局部变量，不重复展开继承值。
- 变量类型由 Go 值推断：string/boolean/long/double/null/json/bytes。
- 不提供变量创建时间与更新时间，DTO 中省略。
- 变量实例 ID 依赖执行/任务 ID，跨引擎恢复后保持稳定。
- 变量值过滤（`variableValueEquals` 等）尚未实现。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 变量实例不存在/跨租户 | 404 | `ENGINE-1601` |
| 非文本变量下载 | 400 | `REST-0131` |
| 非法排序/分页 | 400 | `REST-0123`/`REST-0121` |
| 查询体非法 | 400 | `REST-0120` |
