# 042 任务事件与历史日志过滤

> 文档编号：002-042  
> 更新日期：2026-10-28  
> 对应计划：010 历史、事件与审计；011 REST API 与兼容契约

## 1. 背景

此前任务事件与历史任务日志只支持按任务查询，缺少动作、操作人、实例与时间范围过滤，管理端排查不便。

本期补齐过滤能力，不新增路由。

## 2. 任务事件

`GET /service/runtime/tasks/{id}/events`

查询参数：

| 参数 | 说明 |
| --- | --- |
| `action` / `eventType` | 事件动作，如 create/claim/complete/delegate/resolve |
| `userId` | 操作人 |
| `start` / `size` | 可选分页（仅显式传参时切片） |

- 多参数 AND。
- 返回值仍为事件数组（不改变 Flowable 列表契约）。
- 无匹配返回空数组。

## 3. 历史任务日志

`GET /service/history/historic-task-log-entries`

查询参数：

| 参数 | 说明 |
| --- | --- |
| `taskId` | 任务 ID（原有） |
| `processInstanceId` | 流程实例 ID |
| `userId` | 操作人 |
| `type` / `action` | 日志类型 |
| `from` | 起始时间（含） |
| `to` | 结束时间（含） |
| `start` / `size` | 分页 |

- 时间格式支持 RFC3339 与常见时间字符串；非法时间返回 400（`REST-0146`/`REST-0147`）。
- 先过滤再分页，`total` 为过滤后数量。
- 无匹配返回空页。

## 4. 限制

1. 任务事件分页仅可选切片，不返回 total 分页对象。
2. 历史日志时间比较使用日志时间戳，不区分时区。
3. 未实现按 tenantId 过滤。
4. 不支持按数据内容（data）模糊搜索。

## 5. 测试

- `internal/rest/historic_filters_test.go`：任务事件 action/userId 过滤、历史日志 type/userId/时间、非法时间、空结果。
- 覆盖率：`internal/rest` 90.4%。
