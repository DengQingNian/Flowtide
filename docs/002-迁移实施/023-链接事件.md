# 023 链接事件

> 文档编号：002-023  
> 更新日期：2026-10-28  
> 对应计划：006 流程执行引擎 PVM 设计；005 BPMN 模型、XML 解析与部署校验

## 1. 背景

BPMN 链接事件（Link Event）用于在同一流程内做“跳转”：

- 中间抛出链接事件：令牌跳转到同名捕获链接。
- 中间捕获链接事件：作为跳转目标，本身不等待。

它常用于长流程中跨区域连线，避免绘制过长顺序流。此前解析器忽略 `linkEventDefinition`，运行时会把它当作缺少消息/信号的捕获事件并报错。

## 2. 模型与解析

`model.IntermediateThrowEvent` 与 `model.IntermediateCatchEvent` 新增 `LinkName`。

解析规则：

- 读取 `linkEventDefinition` 的 `name` 属性。
- 抛出与捕获事件使用相同 `name` 完成匹配。
- 缺少 `name` 时按普通中间事件处理。

## 3. 运行时语义

### 3.1 抛出链接

1. 在当前流程中按文档顺序查找同名捕获链接。
2. 找不到返回 400（`ENGINE-0630`）。
3. 记录抛出活动结束，写入捕获活动的历史开始/结束。
4. 从捕获链接的出线继续执行。

### 3.2 捕获链接

- 若通过链接跳转进入：仅作为跳板，随后走自己的出线。
- 若顺序流直接进入捕获链接：记录活动后直接通过，不等待。
- 捕获链接不会创建事件订阅或定时器。

## 4. 历史

- 抛出活动、捕获活动都会产生历史活动记录。
- 跳转后的目标活动正常记录。

## 5. 限制

1. 链接名称只在当前流程内匹配，不跨子流程。
2. 同名捕获事件存在多个时按文档顺序取第一个。
3. 未校验捕获链接是否同时存在入线（BPMN 规范建议不连入线）。
4. 链接事件不参与补偿/错误传播。

- `internal/engine/link_event_test.go`：跳转到用户任务并完成、捕获链接直接通过、缺少捕获链接回滚。
