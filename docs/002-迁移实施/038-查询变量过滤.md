# 038 查询变量过滤

> 文档编号：002-038  
> 更新日期：2026-10-28  
> 对应计划：009 查询端点与历史数据；011 REST API 与兼容契约

## 1. 背景

Flowable 查询请求支持按流程/任务变量过滤结果。此前本仓库只支持实例、任务、状态等基础字段，变量过滤被忽略。

本期为以下 POST 查询增加变量过滤：

- `/service/query/process-instances`
- `/service/query/tasks`
- `/service/query/executions`
- `/service/query/historic-process-instances`
- `/service/query/historic-task-instances`
- `/service/query/historic-activity-instances`

## 2. 请求

~~~json
{
  "variables": [
    {"name": "amount", "value": 100, "operation": "equals"},
    {"name": "status", "value": "open", "operation": "notEquals"},
    {"name": "title", "value": "%urgent%", "operation": "like"},
    {"name": "score", "value": 10, "operation": "greaterThan"}
  ],
  "start": 0,
  "size": 20
}
~~~

- `variables` 为可选数组；空数组不生效。
- 多个条件为 **AND**。
- 缺省 `operation` 为 `equals`。

### 2.1 操作符

| operation | 说明 |
| --- | --- |
| equals | 相等 |
| notEquals | 不等 |
| like | 字符串通配（`%` 任意串，`_` 单字符） |
| greaterThan | 大于 |
| greaterThanOrEqual | 大于等于 |
| lessThan | 小于 |
| lessThanOrEqual | 小于等于 |

大小写不敏感。

## 3. 变量来源

| 查询 | 变量 |
| --- | --- |
| 运行实例 | 实例变量 |
| 运行任务 | 执行可见变量 + 任务局部变量 |
| 执行 | 执行可见变量（含父链与执行局部变量） |
| 历史实例 | 历史变量（按实例） |
| 历史任务 | 历史变量（按任务/实例） |
| 历史活动 | 历史变量（按实例，同一请求内缓存） |

## 4. 匹配语义

- 变量不存在：`equals`/`notEquals` 均视为不满足，避免把缺失变量误判为不等。
- 数值比较：整数/浮点统一按 `float64`。
- 时间比较：支持 RFC3339 字符串与 `time.Time`。
- 布尔：按字符串/布尔值比较。
- 过滤在排序与分页之前执行，返回的 `total` 为过滤后的数量。
- 非法 operation 返回 400。

## 5. 限制

1. 仅支持请求体 `variables`，未实现 Flowable 的 `processVariableValueEquals` 等 query 参数快捷形式。
2. 每个候选项需读取变量（N+1 查询），大结果集性能有限；后续可下推到仓储。
3. 未实现变量类型强制指定（`type` 字段被忽略）。
4. 历史变量取当前历史表快照，不区分变量更新时间。
5. 历史活动变量按实例全量加载并缓存，未按活动任务局部变量细分。

## 6. 测试

- `internal/rest/query_variables_filter_test.go`：六类查询的 equals/notEquals/like/数值比较、执行局部变量、历史活动缓存、缺失变量、非法 operation、分页顺序。
- 覆盖率：`internal/rest` 90.6%。
