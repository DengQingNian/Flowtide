# 043 部署资源内容类型

> 文档编号：002-043  
> 更新日期：2026-10-28  
> 对应计划：012 流程模型仓库；011 REST API 与兼容契约

## 1. 背景

部署资源下载此前统一返回 `application/octet-stream`，浏览器/客户端无法直接识别 BPMN XML、JSON 表单、图片等资源类型。

本期按资源扩展名返回 Content-Type。

## 2. 规则

`GET /service/repository/deployments/{id}/resources/{name}`

| 扩展名 | Content-Type |
| --- | --- |
| `.png` | `image/png` |
| `.svg` | `image/svg+xml` |
| `.json` / `.form` | `application/json` |
| `.xml` / `.bpmn` / `.bpmn20.xml` | `application/xml` |
| `.zip` | `application/zip` |
| `.txt` | `text/plain; charset=utf-8` |
| 其他 | `application/octet-stream` |

- 扩展名判断大小写不敏感。
- 资源不存在仍返回 404。
- 响应体保持原始字节不变。

## 3. 限制

1. 仅按扩展名推断，不读取内容魔数。
2. 未设置 `Content-Disposition`，浏览器可能内联展示。
3. 未实现资源 ETag/缓存头。

## 4. 测试

- `internal/rest/deployment_resource_test.go`：BPMN XML、JSON、二进制资源的 Content-Type。
- 覆盖率：`internal/rest` 90.2%。
