# 026 变量异步兼容端点

> 文档编号：002-026  
> 更新日期：2026-10-28  
> 对应计划：007 变量、表达式与脚本引擎；011 REST API 与兼容契约

## 1. 背景

Flowable 提供 `variables-async` 端点：通过异步作业写入变量，避免长事务阻塞请求。Go 引擎当前没有异步变量作业处理器，为了兼容客户端调用，本期提供**同步语义**的兼容端点：

- 请求立即写入变量并返回 204。
- 不创建异步作业。
- 客户端不需要轮询作业，行为比原版更强（立即生效）。

同时补齐缺失的 `POST /runtime/executions/{id}/variables`。

## 2. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/service/runtime/executions/{id}/variables` | 创建执行变量（201） |
| POST | `/service/runtime/executions/{id}/variables-async` | 同步写入执行变量 |
| PUT | `/service/runtime/executions/{id}/variables-async` | 同步写入执行变量 |
| PUT | `/service/runtime/executions/{id}/variables-async/{name}` | 同步写入单个执行变量 |
| POST | `/service/runtime/process-instances/{id}/variables-async` | 同步写入实例变量 |
| PUT | `/service/runtime/process-instances/{id}/variables-async` | 同步写入实例变量 |
| PUT | `/service/runtime/process-instances/{id}/variables-async/{name}` | 同步写入单个实例变量 |

### 请求体

批量：

~~~json
[
  {"name": "amount", "type": "long", "value": 100},
  {"name": "approved", "value": true}
]
~~~

单个：

~~~json
{"value": "new-value"}
~~~

- 批量支持数组或单对象。
- 空体、非法 JSON、空数组返回 400。
- 执行/实例不存在返回 404。
- 成功返回 204（创建执行变量为 201 + 变量列表）。

## 3. 与 Flowable 的差异

| 项 | Flowable | 本实现 |
| --- | --- | --- |
| 执行时机 | 异步作业 | 同步 |
| 返回 | 202/204 + 作业信息 | 204 |
| 失败处理 | 作业重试/死信 | 直接返回错误 |

调用方无需修改请求格式；若依赖“请求立即返回、后续异步生效”的时序，本实现会在响应前完成写入。

## 4. 限制

1. 未创建异步作业，作业列表中不会出现变量作业。
2. 没有作业级重试与死信语义。
3. 大批量变量写入仍是单事务，可能触发请求超时。
4. 变量类型推断与同步变量接口一致。

## 5. 测试

- `internal/rest/variable_async_test.go`：执行/实例批量与单变量写入、空体、缺失执行。
- 覆盖率：`internal/rest` 90.3%。
