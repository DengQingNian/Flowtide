# 014 流程实例身份链接

> 文档编号：002-014  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；011 REST API 与兼容契约

## 1. 背景

Flowable 用身份链接（Identity Link）表达“谁与流程实例/任务有关系”：

- `participant`：发起人或参与人。
- `candidate`：候选用户/组。
- `custom`：业务自定义关系。

此前只支持任务身份链接（候选用户/组）。本期补齐流程实例级身份链接的增删查、发起人自动登记与持久化。

## 2. 引擎 API

`RuntimeService` 新增：

| 方法 | 说明 |
| --- | --- |
| `ListInstanceIdentityLinks(ctx, processInstanceID)` | 实例身份链接列表 |
| `AddInstanceIdentityLink(ctx, processInstanceID, link)` | 添加链接 |
| `DeleteInstanceIdentityLink(ctx, processInstanceID, family, identityID, type)` | 删除链接 |

`StartRequest` 新增 `UserID`：

- REST 启动实例时由认证信息（`X-User-Id` 或 Basic Auth）填充。
- 非空时自动创建 `participant` 链接并写入历史。

## 3. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/runtime/process-instances/{id}/identitylinks` | 链接列表 |
| POST | `/service/runtime/process-instances/{id}/identitylinks` | 添加链接 |
| DELETE | `/service/runtime/process-instances/{id}/identitylinks/{family}/{identityId}/{type}` | 删除链接 |

添加请求：

~~~json
{
  "type": "participant",
  "userId": "alice"
}
~~~

或：

~~~json
{
  "type": "candidate",
  "groupId": "managers"
}
~~~

规则：

- `type` 必填。
- `userId` 与 `groupId` 必须且只能提供一个，否则 400。
- 成功返回 201 + 链接体。
- 删除成功返回 204；不存在返回 404；`family` 只接受 `users`/`groups`。

## 4. 历史与查询

- 实例链接创建时同步写入历史身份链接（activity 及以上级别）。
- `GET /service/history/historic-process-instances/{id}/identitylinks` 可查询历史链接。
- 删除运行时链接会同步删除对应历史链接。
- 列表按创建时间与 ID 稳定排序。

## 5. 持久化

- 新增 `ACT_RU_IDENTITYLINK` 行映射。
- 导出列：`ID_`、`REV_`、`GROUP_ID_`、`TYPE_`、`USER_ID_`、`TASK_ID_`、`PROC_INST_ID_`、`PROC_DEF_ID_` 及 scope 列。
- 导入时只恢复实例级链接；任务链接继续按任务动态计算。
- 行导入使用实例开始时间作为链接创建时间（`ACT_RU_IDENTITYLINK` 无创建时间列）。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 类型为空 | 400 | `ENGINE-1301` |
| 用户与组未二选一 | 400 | `ENGINE-1302` |
| 参与者类型非法 | 400 | `ENGINE-1303` |
| 链接不存在 | 404 | `ENGINE-1304` |
| 实例不存在/跨租户 | 404 | `ENGINE-0404` |

## 7. 限制

1. 历史身份链接暂无删除端点。
2. 链接创建时间未持久化到 `ACT_RU_IDENTITYLINK`，恢复后使用实例开始时间。
3. 定义级候选发起人（`/repository/process-definitions/{id}/identitylinks`）尚未实现。
4. 身份链接不参与权限判断，仅作为数据记录。

- `internal/rest/instance_links_test.go`：REST 增删查、历史查询、错误路径与租户隔离。
