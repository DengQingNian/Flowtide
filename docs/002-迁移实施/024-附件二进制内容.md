# 024 附件二进制内容

> 文档编号：002-024  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；011 REST API 与兼容契约

## 1. 背景

Flowable 附件支持两种创建方式：

- JSON：外部链接附件（`url`）。
- multipart：文件附件（二进制内容）。

此前只支持 JSON 元数据，缺少文件上传与内容下载。本期补齐：

- `POST /runtime/tasks/{id}/attachments` 的 multipart 支持。
- `GET /runtime/tasks/{id}/attachments/{attachmentId}/content`。
- 附件 DTO 增加 `contentUrl`。
- 内容持久化到 JSON 快照与 `ACT_GE_BYTEARRAY` 行。

## 2. 引擎 API

`TaskService` 新增：

| 方法 | 说明 |
| --- | --- |
| `SetAttachmentContent(ctx, attachmentID, data)` | 写入二进制内容 |
| `GetAttachmentContent(ctx, attachmentID)` | 读取二进制内容 |

规则：

- 附件不存在返回 404。
- 内容为空返回 400。
- 附件/流程实例租户校验沿用现有规则。
- 有内容的附件自动生成 `contentUrl`：
  - 任务附件：`/service/runtime/tasks/{taskId}/attachments/{id}/content`。
  - 流程附件：`/service/runtime/process-instances/{pi}/attachments/{id}/content`。

## 3. 端点

### 3.1 上传

`POST /service/runtime/tasks/{id}/attachments`：

- JSON：`{name, description, type, url}`，默认行为不变。
- multipart：
  - 文件字段任意名称（取第一个文件）。
  - 表单字段：`name`（必填）、`description`、`type`。
  - 缺文件、缺名称、空内容返回 400。
  - 成功返回 201，附件体包含 `contentUrl`。

### 3.2 下载

`GET /service/runtime/tasks/{id}/attachments/{attachmentId}/content`：

- 返回原始字节。
- `Content-Type` 取附件 `type`；非 MIME 类型回退 `application/octet-stream`。
- `Content-Disposition` 使用附件名。
- 任务不匹配、附件不存在或没有内容返回 404。

## 4. 持久化

- 内容存入 `state.AttachmentContents`。
- JSON 快照新增 `attachmentContents` 字段，命令回滚深拷贝。
- SQL 行：
  - `ACT_GE_BYTEARRAY.NAME_ = attachment/{id}`。
  - `ACT_HI_ATTACHMENT.CONTENT_ID_` 指向对应字节数组行。
  - 导入时按名称前缀还原内容，不影响部署资源。

## 5. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 附件内容为空 | 400 | `ENGINE-1105` |
| 附件内容不存在 | 404 | `ENGINE-1106` |
| 附件/任务不存在 | 404 | `ENGINE-0404`/`ENGINE-0805` |
| multipart 缺少文件 | 400 | `REST-0129` |

## 6. 限制

1. 附件内容无独立删除端点，删除附件时内容随附件保留在状态中（后续可补充级联清理）。
2. 流程实例附件内容下载端点尚未开放。
3. 未做内容类型嗅探，完全使用调用方提供的 `type`。
4. 内容大小受全局 64MB 上传限制。

## 7. 测试

- `internal/engine/attachment_content_test.go`：内容读写、缺失/空内容、列表 contentUrl、行导出恢复、快照与克隆。
- `internal/rest/attachment_content_test.go`：multipart 上传、内容下载、列表、外部链接附件、错误路径。
- 覆盖率：`internal/engine` 90.6%，`internal/rest` 90.1%，`internal/persistence/flowable` 90.3%。
