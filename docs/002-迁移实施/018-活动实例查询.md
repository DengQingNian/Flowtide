# 018 活动实例查询

> 文档编号：002-018  
> 更新日期：2026-10-28  
> 对应计划：006 流程执行引擎 PVM 设计；011 REST API 与兼容契约

## 1. 背景

Flowable 的运行时活动实例（Activity Instance）表示当前令牌停留在哪些 BPMN 活动上，用于流程图高亮、运行态监控与排障。

本期新增：

- 运行中活动实例列表。
- 活动实例 POST 组合查询。
- 执行及其子执行的活动 ID 查询。

## 2. 引擎 API

`RuntimeService` 新增：

| 方法 | 说明 |
| --- | --- |
| `ListActivityInstances(ctx, processInstanceID)` | 运行中活动实例 |
| `GetActiveActivityIDs(ctx, executionID)` | 执行及子执行的活动 ID |

`api.ActivityInstance` 字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 活动实例 ID（使用执行 ID） |
| `activityId` | BPMN 活动 ID |
| `activityName` | 活动名称 |
| `activityType` | 活动类型（userTask 等） |
| `processDefinitionId` | 流程定义 ID |
| `processInstanceId` | 流程实例 ID |
| `executionId` | 执行 ID |
| `taskId` | 关联任务 ID |
| `assignee` | 任务处理人 |
| `tenantId` | 租户 |
| `startTime` | 最近一次活动开始时间 |
| `endTime` | 结束时间（运行时为空） |
| `durationInMillis` | 持续时间（运行时为空） |

实现要点：

- 遍历未结束实例与未结束执行，仅保留有 `ActivityID` 的执行。
- 活动名称/类型来自解析后的 BPMN 模型。
- 任务 ID/处理人来自执行上的用户任务。
- 开始时间取该实例/活动最近一条未结束的历史活动记录。
- 租户过滤在引擎层完成。

## 3. 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service/runtime/activity-instances` | 活动实例列表 |
| POST | `/service/query/activity-instances` | 组合查询 |
| GET | `/service/runtime/executions/{id}/activities` | 执行活动 ID 列表 |

GET 过滤参数：`id`、`processInstanceId`、`processDefinitionId`、`activityId`、`activityType`、`activityName`、`activityNameLike`、`taskAssignee`/`assignee`。

排序字段：`id`、`activityId`、`activityType`、`activityName`、`startTime`。

POST 查询额外支持 `start`、`size`、`sort`、`order`，返回分页结构。

执行活动端点返回字符串数组，例如：

~~~json
["approve"]
~~~

## 4. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 执行不存在/跨租户 | 404 | `ENGINE-0405` |
| 非法排序字段/方向 | 400 | `REST-0123` |
| 查询体非法 | 400 | `REST-0120` |
| 分页参数非法 | 400 | `REST-0121` |

## 5. 限制

1. 一个执行只产生一个活动实例；多实例/并行网关下以执行粒度展示。
2. 开始时间依赖历史活动记录，历史级别低于 activity 时为空。
3. 活动实例不包含嵌套子流程的层级结构，仅平铺执行。
4. 运行时活动实例不返回结束时间与持续时间。
