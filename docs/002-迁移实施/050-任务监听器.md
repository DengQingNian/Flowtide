# 050 任务监听器

> 文档编号：002-050  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；006 流程执行引擎 PVM 设计

## 1. 背景

Flowable 允许在 BPMN 用户任务上配置任务监听器，在 create/assignment/complete/delete 事件执行自定义逻辑。此前解析器忽略 `taskListener`。

本期实现 create/complete 事件的安全子集。

## 2. BPMN 配置

~~~xml
<userTask id="task" name="Approve" flowable:assignee="alice">
  <extensionElements>
    <flowable:taskListener event="create" class="onCreate"/>
    <flowable:taskListener event="complete" delegateExpression="onComplete"/>
  </extensionElements>
</userTask>
~~~

- 兼容 `flowable:`/`activiti:`/无前缀。
- `event` 缺省为 `create`。
- 实现方式：`class` 或 `delegateExpression` 作为注册名。
- `expression` 监听器暂不支持，创建任务时返回 400（`ENGINE-1932`）。

## 3. Go 注册

~~~go
engine.RegisterTaskListener("onCreate", func(ctx context.Context, task *api.Task) error {
    return nil
})
~~~

- 监听器拿到任务快照（含 ID/名称/处理人/变量快照）。
- 监听器修改快照不会自动写回流程变量；需要写变量时请使用服务任务/脚本或后续扩展。
- 未注册的监听器使命令失败并整体回滚（`ENGINE-1930`）。
- 监听器返回错误包装为 `ENGINE-1931`，事务回滚。

## 4. 执行时机

| 事件 | 时机 |
| --- | --- |
| create | 任务创建、历史与身份链接写入后，执行等待前 |
| complete | 完成任务变量写入后、任务删除与出线前 |

- 监听器按 BPMN 中定义顺序执行。
- 监听器失败：创建任务时实例启动回滚；完成时任务保留、流程状态不变。

## 5. 限制

1. 未实现 assignment/delete 事件。
2. 未实现表达式监听器与 Java 类加载；`class` 仅作为注册名。
3. 监听器无法通过 task 快照写回变量（快照隔离）。
4. 无任务监听器执行历史记录。
