# 010 独立任务与子任务

> 文档编号：002-010  
> 更新日期：2026-10-28  
> 对应计划：008 任务、身份与表单；011 REST API 与兼容契约

## 1. 背景

Flowable 的任务分为两类：

- **流程任务**：由 BPMN 用户任务创建，绑定执行与流程实例。
- **独立任务**：通过 `TaskService.newTask()` 或 REST `POST /runtime/tasks` 创建，不绑定流程，可用于人工待办、审批附件等场景。

此前 Go 引擎只支持流程任务。本期补齐独立任务、子任务、任务属性更新与删除，并保持流程任务行为不变。

## 2. 模型调整

`api.Task` 新增：

| 字段 | 说明 |
| --- | --- |
| `parentTaskId` | 父任务 ID，用于子任务 |
| `tenantId` | 任务租户；流程任务仍以实例租户为准 |

`api.HistoricTaskInstance` 新增：

| 字段 | 说明 |
| --- | --- |
| `tenantId` | 历史任务租户 |
| `deleteReason` | 删除原因 |

## 3. 引擎 API

`TaskService` 新增四个方法：

| 方法 | 说明 |
| --- | --- |
| `CreateTask(ctx, CreateTaskRequest)` | 创建独立任务 |
| `UpdateTask(ctx, taskID, TaskUpdate)` | 部分更新任务属性 |
| `DeleteTask(ctx, taskID, cascadeHistory, deleteReason)` | 删除独立任务 |
| `ListSubTasks(ctx, taskID)` | 查询子任务 |

`TaskFilter` 新增 `ParentTaskID`，任务列表可按父任务过滤。

### 3.1 创建

- 名称必填，空白名称返回 400。
- 优先级为 0 时使用默认值 50。
- 指定父任务时，父任务必须存在；租户为空则继承父任务租户。
- 子任务租户与父任务不一致返回 409。

### 3.2 更新

`TaskUpdate` 所有字段均为可选：

- 指针为 `nil` 表示不修改。
- `dueDate` 支持显式 `null` 清空。
- 名称、处理人同步到历史任务，并重建身份链接。
- 写入一条 `update` 任务日志。

### 3.3 删除

- 只允许删除独立任务；流程任务返回 403，与 Flowable REST 一致。
- 子任务递归删除。
- `cascadeHistory=true` 时同步删除历史任务、任务日志、身份链接、评论与附件。
- 未级联删除时保留历史，并写入 `deleteReason` 与结束时间。

### 3.4 完成

- 独立任务完成时写入任务历史、任务变量历史与变量明细，然后移除运行时任务。
- 完成请求中的 `variables` 与 `localVariables` 都作为任务局部变量处理。
- 签收、委派、评论、附件、身份链接、任务变量等操作均支持独立任务。

## 4. REST 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/service/runtime/tasks` | 创建独立任务 |
| PUT | `/service/runtime/tasks/{id}` | 部分更新任务 |
| DELETE | `/service/runtime/tasks/{id}` | 删除独立任务 |
| GET | `/service/runtime/tasks/{id}/subtasks` | 子任务列表 |

创建请求示例：

~~~json
{
  "name": "Review",
  "description": "contract",
  "assignee": "alice",
  "priority": 70,
  "dueDate": "2026-11-01T00:00:00Z",
  "parentTaskId": null,
  "tenantId": "tenant-a"
}
~~~

更新请求示例：

~~~json
{
  "assignee": "carol",
  "dueDate": null
}
~~~

- 创建成功返回 201 + 任务体。
- 更新成功返回 200 + 更新后任务。
- 删除成功返回 204。
- 未知字段忽略，兼容客户端携带 `delegationState` 等尚未实现的字段。

## 5. 持久化

- `ACT_RU_TASK.PARENT_TASK_ID_` 与 `TENANT_ID_` 参与行导出与导入。
- 独立任务的 `EXECUTION_ID_` 为空，导入时不再强制要求执行存在。
- `ACT_HI_TASKINST.DELETE_REASON_` 写入删除原因，`TENANT_ID_` 优先取历史任务租户。

## 6. 错误码

| 场景 | HTTP | 错误码 |
| --- | --- | --- |
| 名称空白 | 400 | `ENGINE-0820` |
| 子任务租户不一致 | 409 | `ENGINE-0821` |
| 删除流程任务 | 403 | `ENGINE-0822` |
| 父任务/任务不存在 | 404 | `ENGINE-0805` |
| 跨租户访问 | 404 | `ENGINE-0404` |

## 7. 限制

1. `delegationState`、任务事件、任务监听器尚未实现。
2. 子任务删除为递归删除，未提供单独迁移子任务的接口。
3. 独立任务的评论、附件在未级联删除历史时保留，可继续按任务 ID 查询。
4. 独立任务不参与流程定义、作业与执行树统计。

## 8. 测试

- `internal/engine/task_lifecycle_test.go`：创建、更新、签收、完成、子任务、级联删除、租户隔离、行导入导出。
- `internal/rest/task_lifecycle_test.go`：REST 创建/更新/删除/子任务、空值清空、未知字段、流程任务 403、跨租户 404。
- 覆盖率：`internal/engine` 90.4%，`internal/rest` 90.7%。
