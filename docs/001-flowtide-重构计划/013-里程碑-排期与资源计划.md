## 9. 发布与回滚

- 每两周一个内部 alpha；每月一个 beta；GA 后按 semver。
- 发布物：二进制、镜像、Helm、OpenAPI、CHANGELOG、SBOM。
- 试点：受控停写切换，备份/预检/转换/核对通过后启用唯一执行者；后续按数据库、租户或固定实例集合隔离归属，禁止随机按请求灰度。
- 回退：先完成 Java 读取 Go 数据与续跑验证，使用已验证备份或反向转换恢复；保留旧镜像不能证明数据可回退。
- 禁止在周五/节假日前发布 GA。
