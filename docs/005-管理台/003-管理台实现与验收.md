## 1. 结果

管理台已作为静态资源内嵌进 `flowtide-server`：构建后访问 `/adminpage/#/` 即可完成部署、建模、启动、办理、排障、历史与身份维护，不需要额外静态服务器，也不访问外网。

- 前端工程位于 `admin/`，Vue 3 + TypeScript + Vite + Naive UI，hash 路由。
- 设计器使用 bpmn-js 18 + properties panel 5，独立懒加载，首屏不加载 BPMN 代码。
- Go 侧 `internal/rest/adminpage` 使用 `go:embed all:dist` 挂载 `/adminpage/`，提供 SPA 回退、长缓存指纹资源、中文 404/占位页与统一安全头。
- 管理台不新增任何 REST 业务端点，不注入认证头与租户头；服务端认证、RBAC 与租户绑定保持原样。

## 4. 关键实现

### 4.1 构建与嵌入

`make admin-build` 执行 `npm ci && npm run build`，把 `admin/dist` 复制到 `internal/rest/adminpage/dist`，再由 `go:embed` 编译进二进制。`make build` 先执行该目标。

| 请求 | 行为 |
| --- | --- |
| `GET /adminpage/` | `index.html`，`no-store` |
| `GET /adminpage/assets/*` | 指纹资源，一年 immutable 缓存 |
| `GET /adminpage/<无扩展名>` | SPA 回退 `index.html` |
| `GET /adminpage/<缺失资源>` | 中文 HTML 404 |
| `GET /adminpage` | 301 到 `/adminpage/`，保留查询串 |
| `GET /` | 302 到 `/adminpage/` |
| 产物缺失 | 200 中文“管理台未构建”占位页 |

安全头：`X-Content-Type-Options: nosniff`、`Referrer-Policy: same-origin`、CSP（`default-src 'self'`，仅允许同源脚本与连接，样式允许内联，图片允许 data/blob）。

### 4.2 前端分层

- `api/client.ts`：同源 fetch、20 秒默认超时、`{code,message,exception}` 错误映射、分页信封与二进制/文本解析；写操作不自动重试。
- `api/<域>.ts`：按域封装真实端点；响应类型与 `internal/rest` handler 对齐。
- `components/`：通用页面头、筛选栏、远程分页表、状态标签、错误块、JSON/XML 查看器、变量编辑器/列表、BPMN 图、启动实例弹窗与任务表单。
- `stores/ui.ts`：侧栏、主题、服务健康、401/403 提示与全局加载。
- `design/`：bpmn-js 设计器/查看器、中文翻译、最小 BPMN 与校验工具；设计器 chunk 懒加载。

### 4.3 认证与权限边界

- 不保存、不注入任何凭据；不解析 JWT；不提供模拟登录或跳过认证的开关。
- 服务端启用 Basic/JWT/mTLS 时页面仍可打开；数据请求 401 时顶部常驻说明，页面与表单内容保留。
- 403 展示服务端原文，不隐藏入口、不跳转。
- 不发送 `X-Tenant-Id`，使用服务端默认/绑定租户。

### 4.4 与需求清单的契约差异

开发过程中以实际 handler 为准，以下差异已在界面降级处理：

| 项 | 实际契约 | 界面处理 |
| --- | --- | --- |
| 部署列表过滤 | 仅 `start/size/tenantId`，无 `nameLike`/排序/资源数 | 服务端分页 + 当前页本地筛选；资源数进入详情查看 |
| 定义列表 | 无 `latestVersion`/`suspended` 参数 | 拉取后在本地按 Key 分组与状态过滤 |
| 实例活动 | 无 `/process-instances/{id}/activities` | 流程图使用 `/diagram` 图片或定义 XML 高亮；活动信息从实例 DTO/任务推断 |
| 历史过滤 | 复杂时间/办理人过滤只在 POST `/query/*` | 历史页面优先使用 POST 查询端点 |
| 历史任务表单 | `GET /historic-task-instances/{id}/form` 恒 400 | 不提供假入口，展示表单不可用说明 |
| 引擎信息 | `/management/engine` 仅 name/version/historyLevel/closed | Schema/租户/存储模式从 `engine-properties` 补充 |
| 表结构 | 仅列名/类型 | 不展示 nullable/PK/FK，避免编造 |
| 审计日志 | 仅 `start/size` | 服务端分页 + 当前页本地筛选 |
