# 001 管理台需求清单

> 文档编号：005-001
> 更新日期：2026-10-30
> 版本：v1.1（本期不实现权限控制，认证与授权能力延期）
> 状态：待评审
> 关联计划：[002 管理台开发计划](002-管理台开发计划.md)

## 1. 背景

Flowtide 当前对外只有 REST 与命令行工具。242 个 `/service` 方法端点覆盖部署、实例、任务、作业、历史、身份与引擎管理，但日常运维必须手写 curl 或借助外部工具：

- 无法直观看到流程定义、实例执行位置与失败作业；
- 无法在线建模、改图、重新部署；
- 身份目录、引擎属性、ACT_* 表数据只能逐条查接口；
- 上游 Flowable 7.0 起开源版不再附带 UI，界面能力进入商业产品（Design/Work/Control），本项目无法直接复用。

本项目在服务端内嵌一个只读优先、可写管理台，用浏览器完成"建模 → 部署 → 启动 → 办理 → 排障 → 归档 → 身份维护"的闭环，交付形态仍是单二进制、无 JVM、无外部静态资源依赖。

**本期定位**：面向开发、测试与内网运维的管理工具，默认部署在受控网络。登录、会话、角色菜单等权限控制能力延后实现，服务端原有的认证与 RBAC 保持不变。

## 2. 目标与成功标准

| 编号 | 目标 | 成功标准 |
| --- | --- | --- |
| G1 | 单二进制内嵌 | `make build` 产物直接访问 `/adminpage/#/` 可用，不额外部署静态服务器、不访问外网 |
| G2 | 运维闭环 | 从建模到任务完成、失败作业重试、历史查询全部可在界面完成 |
| G3 | 数据全覆盖 | P0 页面覆盖部署、定义、模型、实例、任务、作业、历史、身份、表数据九类数据 |
| G4 | 设计能力 | 内置 bpmn.io 设计器，支持 BPMN 2.0 建模、属性编辑、校验、保存、部署 |
| G5 | 风格一致 | 与文档站同一套 Notion 风格令牌与 Naive UI 主题，浅色/深色一致 |
| G6 | 质量门禁 | 前端行覆盖率 ≥ 0.90，Go 新增代码纳入既有 0.90 门禁，`make check` 全绿 |
| G7 | 访问边界 | 本期不实现登录与权限控制；管理台不保存凭据，部署在受控网络，服务端认证配置保持原样 |

## 3. 访问前提与边界

本期管理台**不做权限控制**，范围包括：

| 能力 | 本期 | 说明 |
| --- | --- | --- |
| 登录页、登出 | 不做 | 不收集用户名、密码、令牌 |
| 会话探测 | 不做 | 不新增会话端点，不显示当前主体 |
| 角色菜单、按钮级权限 | 不做 | 全部页面与操作入口可见 |
| 403 权限说明页 | 不做 | 服务端返回的 401/403 原样提示 |
| 租户切换 | 不做 | 不发送 `X-Tenant-Id`，使用服务端默认租户 |

运行前提：

1. 服务端未启用认证时，管理台全部功能可用（开发、测试、内网运维的默认形态）。
2. 服务端启用 Basic/JWT/mTLS 时，管理台本身仍可打开，但数据请求会收到 401；界面给出明确说明，不提供登录入口。此时应由前置反向代理完成认证并注入请求头，或在后续版本补齐登录能力。
3. 服务端 RBAC 与租户绑定继续生效。界面不做前端判断，管理员与只读账号看到相同入口，差异由接口 403 体现。
4. 部署建议：仅监听回环或内网地址；确需公网访问时，必须前置网关做认证与访问控制。

## 4. 范围

### 4.1 本期实现

- 全局框架：导航、主题、错误处理、加载与空态、危险操作确认。
- 仪表盘：引擎信息、关键计数、失败作业、最近部署与实例。
- 部署与流程定义：上传部署、资源查看下载、定义详情、XML/图片、启动、挂起激活、身份链接、迁移入口。
- 流程模型与 BPMN 设计器：模型 CRUD、bpmn.io 设计器、属性面板、校验、保存、部署、只读查看器与运行态高亮。
- 运行态：实例列表/详情/变量/任务/评论/附件/身份链接/迁移/状态变更/删除/注入。
- 任务：列表、详情、表单渲染、签收/完成/委派/改派/删除、变量、评论、附件、子任务、独立任务创建。
- 作业：可执行/定时/挂起/死信四类，重试、move、reschedule、删除、异常栈、立即执行到期作业。
- 批处理：列表、详情、分片、摘要、文档、删除。
- 历史：历史流程/任务/活动/变量/明细，详情、变量数据、评论、删除。
- 身份：用户、组、角色、成员关系、用户信息、头像、密码。
- 引擎管理：引擎属性 CRUD、ACT_* 表清单/列元数据/数据浏览、审计日志、指标、健康检查。
- 系统：版本信息、端点目录、根路径跳转。

### 4.2 本期不做

| 项 | 原因 |
| --- | --- |
| 登录、会话、RBAC 菜单、403 页、租户切换 | 本期明确不做权限控制，后续版本补齐 |
| CMMN/DMN/Form 设计器 | 引擎侧能力未完成，设计器工作量独立 |
| 流程模型版本对比与合并 | 模型只有递增版本字段，无 diff 语义 |
| 租户管理（创建/删除租户） | `ACT_*` 无租户主数据表 |
| OIDC 授权码登录、SSO 登出 | 服务端只有 JWT 验签，无令牌签发端点 |
| 国际化（英文） | 现有文档与注释均为中文 |
| 移动端专项适配 | 仅保证 ≥1024px 可用 |
| 实时协作、WebSocket 推送 | 依赖服务端事件流，暂不引入 |
| ACT_* 表数据编辑 | 管理端只读；写数据走业务接口，避免绕过引擎一致性 |

## 8. 未实现权限控制的降级表现

| 场景 | 界面表现 |
| --- | --- |
| 服务端未启用认证 | 全部页面与操作可用，无任何登录提示 |
| 服务端启用 Basic/JWT/mTLS，浏览器未携带凭据 | 页面正常打开，数据请求 401；顶部提示"服务端要求认证，本期管理台未提供登录"，附排查说明 |
| 认证由反向代理注入 | 与未启用认证一致，界面无感知 |
| RBAC 返回 403 | 操作失败提示原始 `message`，页面保留，不跳转、不清空表单 |
| 账号绑定固定租户 | 数据按服务端绑定租户返回，界面不提供切换入口 |
| 服务离线或 `/readyz` 失败 | 全局横幅提示，提供"重试"与"查看健康检查" |

以上降级必须在验收中逐项验证，避免出现"页面崩溃/无限重定向/空白"。

## 10. 验收标准

- [ ] `make build` 后单二进制启动，浏览器访问 `/adminpage/#/` 直接进入仪表盘。
- [ ] 新建模型 → 设计器画用户任务 → 保存 → 部署 → 启动实例 → 任务列表办理 → 实例结束 → 历史可见，全流程无 curl。
- [ ] 上传含两个流程的 ZIP 部署，资源可预览/下载，删除后定义列表同步消失。
- [ ] 构造失败作业进入死信，界面查看异常栈并重试成功。
- [ ] 表数据浏览可分页、排序，二进制列有明确提示。
- [ ] 服务端开启 Basic 认证后，管理台页面可打开，401 有明确说明且不白屏、不循环跳转。
- [ ] RBAC 拒绝的操作显示服务端原文，当前页面与已填内容不丢失。
- [ ] 刷新任意 hash 路由、断网后再次加载静态资源均正常（离线可用）。
- [ ] `npm test` 覆盖率 ≥ 0.90；`make check` 全绿；e2e 冒烟通过。
- [ ] 页面无外部网络请求；CSP 生效；不保存任何凭据。
