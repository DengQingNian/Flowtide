## 1. 变量系统

### 1.1 作用域模型

~~~mermaid
flowchart TD
    PI[流程实例根作用域] --> SUB[子流程作用域]
    SUB --> EXEC[并发执行作用域]
    EXEC --> TASK[任务局部作用域]
    TASK --> TMP[瞬态变量作用域]
~~~

| 作用域 | 存储位置 | 生命周期 | 说明 |
| --- | --- | --- | --- |
| 流程实例 | `ACT_RU_VARIABLE.PROC_INST_ID_` + `EXECUTION_ID_` 为根 | 实例结束 | 全局变量 |
| 执行 | `ACT_RU_VARIABLE.EXECUTION_ID_` | 执行删除 | 局部变量 |
| 任务 | `ACT_RU_VARIABLE.TASK_ID_` | 任务完成 | 任务局部 |
| 瞬态 | 内存 | 当前命令 | 不落库、不传播 |
| 历史 | `ACT_HI_VARINST` | 按保留策略 | 只读查询 |

查找顺序：**任务局部 → 当前执行 → 父执行 → … → 流程实例**。写入规则：

- `SetVariable`：写到当前作用域最近的已存在变量；不存在则写流程实例根（Flowable 语义）。
- `SetVariableLocal`：只写当前作用域。
- `RemoveVariable`：从最近的已存在作用域删除。
- `SetVariableTransient`：只写内存，命令结束即消失。

### 1.2 类型系统

| 类型名 | Go 类型 | 存储列 | 说明 |
| --- | --- | --- | --- |
| `string` | `string` | `TEXT_` | 短文本（≤ 4000） |
| `longString` | `string` | `BYTEARRAY_ID_` | 长文本，UTF-8；注意大小写与 Flowable 一致 |
| `long` | `int64` | `LONG_` | 整数 |
| `integer` | `int32` | `LONG_` | 兼容 Java Integer |
| `short` | `int16` | `LONG_` | 兼容 Java Short |
| `double` | `float64` | `DOUBLE_` | 浮点 |
| `bigdecimal` | `decimal.Decimal` | `TEXT_` | 精确小数 |
| `biginteger` | `*big.Int` | `TEXT_` | 大整数 |
| `boolean` | `bool` | `LONG_` | 0/1 |
| `date` | `time.Time` | `LONG_` 或 `TEXT_` | 以毫秒或 ISO-8601 存储，方言统一 |
| `instant` | `time.Time` | `TEXT_` | ISO-8601 带时区 |
| `localdate` | `time.Time` | `TEXT_` | 仅日期 |
| `localdatetime` | `time.Time` | `TEXT_` | 本地日期时间 |
| `json` | `any` | `TEXT_` | JSON 文本，保留结构 |
| `bytes` | `[]byte` | `BYTEARRAY_ID_` | 二进制 |
| `serializable` | `[]byte` | `BYTEARRAY_ID_` | Java 序列化，Go 不解释 |
| `null` | `nil` | — | 显式空值 |
| `uuid` | `string` | `TEXT_` | UUID |

> 兼容说明：Flowable 还包含 `jodadate`、`jodadatetime`、`longJson`、`emptyCollection`、`jpa-entity`、`jpa-entity-list` 等历史/JPA 类型。Go 版不内置这些类型；启动或读取时遇到会返回 `ErrUnsupportedVariableType` 并给出迁移提示，避免静默丢失语义。

类型推断规则：

1. 写入 `nil` → `null`。
2. `int`/`int32`/`int64` → `long`（保留范围）。
3. `float32`/`float64` → `double`。
4. `map[string]any`/切片/结构体 → `json`（需可 JSON 序列化）。
5. `time.Time` → `date`（可配置 instant）。
6. 未注册类型 → 返回 `ErrUnsupportedVariableType`，不静默转字符串。

### 1.3 序列化

~~~go
// VariableType 定义一种变量类型的读写行为。
type VariableType interface {
    // Name 返回类型名。
    // @return 类型名
    Name() string
    // Encode 将 Go 值编码为存储字段。
    // @param value Go 值
    // @return 存储字段
    // @return 编码错误
    Encode(value any) (ValueFields, error)
    // Decode 将存储字段还原为 Go 值。
    // @param fields 存储字段
    // @return Go 值
    // @return 解码错误
    Decode(fields ValueFields) (any, error)
}

// ValueFields 是变量在数据库中的列值集合。
type ValueFields struct {
    Text       *string // TEXT_
    Text2      *string // TEXT2_
    Long       *int64  // LONG_
    Double     *float64 // DOUBLE_
    ByteArray  []byte  // 通过 BYTEARRAY_ID_ 关联
    TypeName   string  // TYPE_
    MetaInfo   *string // META_INFO_
}
~~~

约束：

- JSON 序列化使用 `encoding/json`，禁止 `gob`（跨版本不稳定）。
- 大文本（> 4000 字符）自动转 `longstring`。
- 二进制变量单值 ≤ 10MB，可通过配置调整；超过返回错误。
- `serializable` 只读写字节，不解释 Java 对象；UI 展示为"不可读二进制"。
- 日期统一 UTC 存取；REST 输出 ISO-8601。

### 1.4 变量 API

~~~go
// VariableScope 是变量读写的最小接口。
type VariableScope interface {
    // GetVariable 按作用域链查找变量。
    // @param name 变量名
    // @return 变量值
    // @return 是否存在
    GetVariable(name string) (any, bool)
    // GetVariableLocal 仅查当前作用域。
    // @param name 变量名
    // @return 变量值
    // @return 是否存在
    GetVariableLocal(name string) (any, bool)
    // SetVariable 写入最近的已存在作用域，否则写流程实例。
    // @param name 变量名
    // @param value 变量值
    SetVariable(name string, value any)
    // SetVariableLocal 只写当前作用域。
    // @param name 变量名
    // @param value 变量值
    SetVariableLocal(name string, value any)
    // RemoveVariable 从最近作用域删除变量。
    // @param name 变量名
    RemoveVariable(name string)
    // GetVariables 返回当前作用域可见变量快照。
    // @return 变量快照
    GetVariables() map[string]any
}
~~~

### 1.5 变量监听器

- 变量写入/更新/删除时触发；监听器可修改值或阻止（返回错误）。
- 监听器在事务内同步执行；异常回滚命令。
- 监听器不得递归修改同一变量（检测并报错）。
- 用于 BPMN 的 `variableListener` 事件定义与任务监听器。

## 2. 表达式引擎（UEL 兼容）

### 2.1 兼容目标

| 能力 | 优先级 | 说明 |
| --- | --- | --- |
| 字面量/算术/比较/逻辑 | P0 | 完整 |
| 变量与属性访问 | P0 | `execution`、`task`、流程变量 |
| Map/List 下标 | P0 | `vars['x']`、`list[0]` |
| 三元表达式 | P0 | `a ? b : c` |
| 方法调用 | P1 | 仅白名单类型 |
| 内置函数 | P1 | 日期、字符串、集合、变量 |
| Bean 解析 | P1 | 注册表注入 |
| 空安全导航 | P2 | 参考实现不支持则不做 |
| 静态类型检查 | P2 | 可选编译期检查 |

### 2.2 语法（EBNF）

~~~ebnf
expr        := ternary ;
ternary     := or ( '?' expr ':' expr )? ;
or          := and ( ( '||' | 'or' ) and )* ;
and         := equality ( ( '&&' | 'and' ) equality )* ;
equality    := relational ( ( '==' | '!=' | 'eq' | 'ne' ) relational )* ;
relational  := additive ( ( '<' | '>' | '<=' | '>=' | 'lt' | 'gt' | 'le' | 'ge' ) additive )* ;
additive    := multiplicative ( ( '+' | '-' ) multiplicative )* ;
multiplicative := unary ( ( '*' | '/' | '%' | 'div' | 'mod' ) unary )* ;
unary       := ( '!' | 'not' | '-' | 'empty' ) unary | postfix ;
postfix     := primary ( '.' IDENT | '[' expr ']' | '(' args? ')' )* ;
primary     := literal | IDENT | '(' expr ')' ;
args        := expr ( ',' expr )* ;
literal     := STRING | NUMBER | 'true' | 'false' | 'null' ;
~~~

支持两种定界符：`${...}` 与 `#{...}`；若整个字符串不含定界符，按字面量处理（Flowable 行为）。

### 2.3 AST 与求值器

~~~go
// Expression 是编译后的表达式。
type Expression interface {
    // Eval 在给定环境中求值。
    // @param ctx 上下文
    // @param env 求值环境
    // @return 结果
    // @return 错误
    Eval(ctx context.Context, env *Env) (any, error)
    // Source 返回原始表达式文本。
    // @return 表达式文本
    Source() string
}

// Env 提供变量、属性、方法与函数解析。
type Env struct {
    Vars      map[string]any            // 变量快照
    Beans     map[string]any            // 注册 Bean
    Functions map[string]Function       // 函数表
    Resolver  PropertyResolver          // 属性/方法解析
}

// Compile 编译表达式；相同文本命中缓存。
// @param source 表达式文本
// @return 编译结果
// @return 编译错误
func Compile(source string) (Expression, error) { /* ... */ }
~~~

实现要点：

1. **词法**：手写扫描器，支持单/双引号、转义、数字（整数/小数/科学计数）、Unicode 标识符。
2. **语法**：Pratt 解析器，优先级与表一致；错误带列号。
3. **求值**：树遍历；短路逻辑；类型转换规则显式定义。
4. **缓存**：`sync.Map[source]Expression`；函数表版本变化时整体失效。
5. **超时**：每 1,000 个 AST 节点检查一次 `ctx.Done()`；单次求值默认上限 100ms。
6. **深度**：AST 深度 ≤ 100，表达式长度 ≤ 8KB。

### 2.4 类型转换

| 运算 | 规则 |
| --- | --- |
| `+` | 任一操作数为字符串 → 字符串拼接；否则数值相加 |
| 比较 | 数值按 float64/int64 提升；字符串字典序；时间按 Unix 毫秒 |
| `==` | 先比较类型；数值跨类型按值比较；`nil == null` 为 true |
| 逻辑 | 仅接受 bool；其他类型报错（不静默真值） |
| 属性 | map 按键；struct 按字段/方法；nil → 报错或 null（可配置） |
| 下标 | map/slice/array/string；越界报错 |

### 2.5 属性与方法解析

~~~go
// PropertyResolver 解析属性与方法。
type PropertyResolver interface {
    // GetProperty 读取属性。
    // @param target 目标对象
    // @param name 属性名
    // @return 值
    // @return 是否存在
    GetProperty(target any, name string) (any, bool)
    // CallMethod 调用方法。
    // @param target 目标对象
    // @param name 方法名
    // @param args 参数
    // @return 结果
    // @return 错误
    CallMethod(target any, name string, args []any) (any, error)
}
~~~

白名单：

- `*ExecutionEntity`：`getVariable`、`setVariable`、`getVariableLocal`、`hasVariable`、`getProcessInstanceId`、`getCurrentActivityId`、`getBusinessKey` 等只读/受控方法。
- `*TaskEntity`：`getAssignee`、`getOwner`、`getTaskDefinitionKey`、`getVariable` 等。
- `map[string]any`、`[]any`、`string`、数值、`time.Time`：安全方法。
- 其他类型：只允许导出字段读取，禁止方法调用。

禁止：

- `reflect` 访问未导出字段。
- 调用 `os`、`net`、`exec`、`runtime` 等危险包类型。
- 通过 `interface{}` 反射构造任意类型。

## 3. 脚本任务

### 3.1 支持矩阵

| 脚本格式 | 引擎 | 优先级 | 说明 |
| --- | --- | --- | --- |
| `javascript` / `js` | goja | P0 | ES5.1+，可中断 |
| `starlark` | go.starlark.net | P1 | 确定性、易沙箱 |
| `groovy` | 不支持 | — | 返回 `ENGINE-0701`，迁移时改写 |
| `juel` | 表达式引擎 | P1 | 简单表达式 |
| `lua` | 可选 | P3 | 三方库引入需评估 |

### 3.2 接口

~~~go
// ScriptEngine 执行脚本任务。
type ScriptEngine interface {
    // Name 返回脚本格式名。
    // @return 格式名
    Name() string
    // Compile 编译脚本。
    // @param source 脚本源码
    // @return 可执行脚本
    // @return 编译错误
    Compile(source string) (CompiledScript, error)
}

// CompiledScript 是可执行脚本。
type CompiledScript interface {
    // Run 在绑定环境中执行。
    // @param ctx 上下文，用于超时与取消
    // @param bindings 变量绑定
    // @return 结果
    // @return 错误
    Run(ctx context.Context, bindings map[string]any) (any, error)
}
~~~

### 3.3 绑定与结果

- 默认绑定：流程变量、`execution`、`task`、`authenticatedUserId`。
- 脚本返回值写入 `resultVariable`（若配置）。
- `autoStoreVariables=true` 时，把脚本顶层变量写回流程变量（仅简单类型）；默认 false。
- 脚本内不得直接操作数据库；需要副作用请调用注册函数或委托。

### 3.4 安全与资源限制

| 风险 | 措施 |
| --- | --- |
| 死循环 | goja 中断通道 + 超时（默认 5s） |
| 内存爆炸 | 限制输入/输出大小；进程级内存上限；可选独立 worker 进程 |
| 文件/网络访问 | 不注入 `os`、`net`、`http` 对象 |
| 反射逃逸 | 不暴露 Go 反射对象；只传基础类型与受控包装 |
| 无限递归 | 设置最大调用栈 |
| 敏感信息 | 绑定前脱敏；禁止读取环境变量 |

> goja 无法设置硬内存上限；对不可信脚本，建议部署时启用独立 worker 进程或禁用脚本任务。文档与运维手册必须明确该风险。

## 4. 性能与缓存

- 表达式编译缓存命中率目标 > 95%。
- 求值器避免反射：对高频类型（map、execution、task）使用类型断言快路径。
- 变量读取批量加载：同一执行树一次查询取回全部变量，避免 N+1。
- JSON 变量解析惰性化：只有表达式访问时才反序列化。
- 基准：10 万次简单条件求值 < 200ms（单核）。
