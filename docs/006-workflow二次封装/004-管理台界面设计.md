# 006 系列文档之四：管理台界面设计（接口 ↔ 界面操作映射）

> 对标蓝本：example-cloud-platform-admin 工作流部分（Vue2 + ElementUI，调研 007 篇）。
> 落地载体：Flowtide 现有管理台 `admin/`（Vue 3 + TS + Vite + Naive UI + bpmn-js 18，go:embed 单二进制）；对标信息架构/页面/操作/协议，不移植 Vue2 组件库。
> **每个门面接口都有对应的管理台界面操作；没有界面归属的接口一律不进本期门面。**

## 1. 界面相关决策（引用 001 文档 D7-D12）

D7 按钮权限=全量显示+menuCode 服务端忽略；D8 门面路径 Java 兼容形态（保留 deplay 兼容拼写 + deploy 别名）；D9 内置静态字典 `/workflow/dict/{code}`；D10 内置身份库树接口 `/workflow/identity/*`（预留外部 auth 适配器）；D11 workflow_model 一表两页（分类树投影 `/workflow/category/**` + 模型全字段 `/workflow/model/**`）；D12 BPMN 设计器纳入本期（画布复用 admin 现有 bpmn-js，属性面板新写）。

## 3. 接口 ↔ 界面操作映射总表

### 3.1 流程分类页

| 界面操作 | 接口 | 能力 |
| --- | --- | --- |
| 树形列表（懒加载、拖拽排序、名称/代号搜索） | GET /workflow/category/listChildren | P5.1 |
| 新增（弹窗：所属分类树、分类名称*、分类代号*、排序、可见、启用、备注；"保存继续添加"） | POST /workflow/category/add | P5.1 |
| 添加同级/子级（预填 parentId） | 同上 | P5.1 |
| 编辑/可见·启用开关 | PUT /workflow/category/edit | P5.1 |
| 导入分类（zip ≤4MB、重名去重） | POST /workflow/category/import | P5.1 |
| 导出分类（勾选→zip） | GET /workflow/category/export?categoryIds= | P5.1 |
| 分类树选择数据源（复用） | GET /workflow/category/list；/search/list | P5.1 |

### 3.2 流程模型页

| 界面操作 | 接口 | 能力 |
| --- | --- | --- |
| 列表（系统树、消息渠道多选、退回排序、相同处理人自动办结、最后部署时间；行内批量编辑） | GET /workflow/model/list；/findById | P5.1 |
| 新增/编辑（所属系统*、模型名称*、模型代号*、启用、退回步骤排序、排序、渠道、含协办意见、备注） | POST/PUT /workflow/model(add\|edit) | P5.1 |
| 部署（确认弹窗→结果提示） | POST /workflow/process/deplay {modelId,tenantId}（兼容）/ deploy | P5.1 + P3.6 |
| 导出/导入流程（zip） | GET /workflow/process/exportProcess?modelIds=；POST /workflow/process/importProcess | P5.1 |
| 复制到其他系统 | POST /workflow/process/copyProcess {resourceId, modelIdList} | P5.1 |
| 消息渠道同步（渠道 checkbox + 是否同步在途流程） | POST /workflow/process/channelSync | P4.3 + P5.1 |
| 左树（系统资源树） | GET /workflow/identity/resourceTree | F6.1 |

### 3.3 流程配置页（三 Tab）

**Tab1 步骤管理**：步骤列表（模型态/实例态切换；四组列：基础/高级/消息/权限，30+ 字段全集见调研 007 §3.3.1）→ GET /workflow/step/list；实例态 GET /workflow/hisstep/list（param.processInstanceId）；新增/编辑/行复制/删除/拖拽排序 → POST|PUT /workflow/step(add|edit)、/workflow/hisstep(add|edit)、DELETE /workflow/step；backStepCodes 多选仅可选 sort 更小的步骤（前端约束+后端校验兜底）。

**Tab2 流程模板（BPMN 设计器）**：

| 界面操作 | 接口/实现 |
| --- | --- |
| 打开画布（模型态/实例态读 XML） | GET /workflow/process/getModelJsonByType/?customModelId=&dataObtainType=0\|1；GET /workflow/process/getHisModelJson/ |
| 属性面板-执行类型/执行者（单人/多人 person/org/role + executorList、${initiator}） | BPMN 扩展属性 executorNumType/assignee/candidateUsers/candidateGroups/executorType/executorList（D6） |
| 属性面板-多实例/会签（时序、weightType average/custom、逐人权重抽屉、阈值、完成比例） | BPMN 扩展属性 weightType/weightList/weightThreshold/completionCondition（D6） |
| 属性面板-连线条件（普通/默认/条件、direction 隐藏写入） | BPMN conditionExpression（D6） |
| 属性面板-监听器/输入输出参数/扩展属性 | flowable:ExecutionListener/TaskListener/In/Out/Properties |
| 保存（模型态） | POST /workflow/process/save/xml（P5.1 + P3.6 校验） |
| 实例态保存 | POST /workflow/process/updateHisModelXml（接口形态保留，Go 内部改为衍生部署，D1） |
| 部署 | POST /workflow/process/deplay |

**Tab3 流程规则**：静态文档页（建模约定：_begin/_end、Draft/Sign、${initiator}、权重表达式等）。

### 3.4 待办/已办页

| 界面操作 | 接口 | 能力 |
| --- | --- | --- |
| 待办列表（搜索：处理人/标题/流程名称/步骤/发送人/下发时间；左树系统过滤） | GET /workflow/process/task/all/todoList | P1.8 |
| 已办列表（+完成时间） | GET /workflow/process/task/all/doneList | P1.8 |
| 办理（Go 增强）：审批弹窗（意见*、下一步骤多选、每步骤选人）→ 提交 | 弹窗数据 GET /workflow/process/nextUserTask/list?taskId=（推演）；提交 POST /workflow/process/complete/sign（CompleteTaskVo 协议） | P1.5 + P5.3 |
| 审批弹窗-退回模式 | GET /workflow/process/backNodes/list?taskId= | P2.1 |
| 转办/委派（行操作） | POST /workflow/process/transfer/task；/delegate/task | P4.1 |
| 催办（Go 增强：立即发送） | POST /workflow/remind/sendNow {taskId} | P4.3 |
| 流程图弹窗（高亮已走/在走，节点悬浮办理记录） | GET /workflow/process/getHighLightedNodeVoByProcessInstanceId；getOneActivityVoByProcessInstanceIdAndActivityId | P5.5 |
| 审批时间线 | GET /workflow/process/history/step/list/{taskId}（Java 桩，Go 实现） | P1.8 |
| 批量删除 | DELETE /workflow/process/task | P1.8 |

### 3.5 流程实例页

| 界面操作 | 接口 | 能力 |
| --- | --- | --- |
| 实例列表（状态 0 已结束/1 激活/2 挂起；业务ID button） | GET /workflow/process/instance/all/list | P1.8 |
| 暂停/激活/终止（confirm） | POST /workflow/process/suspend\|activate\|stop/processInstance/{id} | P2.6 |
| 业务变量弹窗（搜索/增删改行/全量保存/修改红点） | GET /workflow/process/getEntityByBusinessId/{businessKey}；POST /workflow/process/updateEntityByBusinessId/{businessKey} | P1.8 |
| 按条件批量删除（系统代号*、流程代号、发起时间段；警示级联不可恢复） | POST /workflow/process/deleteProcessByParams | P2.6 |
| 实例级流程改造（跳配置页实例态） | 前端路由 ?instanceId= → hisstep/updateHisModelXml | P5.2（D1） |
| 重置/重激活（Go 增强） | POST /workflow/process/reset/processInstance/{id}；POST /workflow/process/reactivate（可指定 activityId） | P2.5/P2.6 |
| 撤回（Go 增强） | POST /workflow/process/rollback {taskId} | P2.3 |
| 直送（Go 增强） | POST /workflow/process/completeToTargetActivity | P2.4 |

### 3.6 委托配置页

列表 GET /workflow/delegate/list；新增/编辑（委托人*、受托人*人员树、委托条件*字典、委托时限*、系统代号*、备注*；后端校验时间重叠/禁止传递——错误 toast 明示规则）POST/PUT /workflow/delegate(add|edit)；启用/停用 PUT /workflow/delegate/edit；人员树 GET /workflow/identity/orgTree、/accountSearch。

### 3.7 催办配置页

列表（所属系统、流程名称[button]、步骤名称、启用预警/延时、创建时间；勾选批量删除）GET /workflow/remind/getPageList、DELETE /workflow/remind/deleteBatch/{ids}；新增/编辑/查看全屏表单（级联：所属系统*→流程[弹窗选]→步骤多选）+ 预警提醒块（启用开关 + 添加人员/角色 + 目标表格：启用/人员/提前量 ahead/再次提醒 retry/间隔/次数/单位/按计划完成时间/删除；默认"当前处理人"行 executorId=-1111 置顶不可删）+ 延时提醒块（delay）；保存 POST /workflow/remind/add|edit、详情 GET /workflow/remind/getWorkflowRemind/{id}；手动催办 POST /workflow/remind/sendNow。

### 3.8 流程异常页

异常列表 GET /workflow/exception/list（标题/流程名称/异常类型[字典+checkbox]/异常信息/发起人/时间）；只读详情；标记已处理/忽略 POST /workflow/exception/handle {ids, action}（Go 新增，handle_status 列）；重发相关待办 POST /workflow/exception/regenerate {processInstanceId}（Go 新增可选）。

### 3.9 公共组件与首页

审批弹窗/审批时间线/流程图预览（高亮+悬浮）/选流程弹窗（findModelAndStepPageList）/字典 GET /workflow/dict/{code}/身份树 /workflow/identity/*；首页监控卡片 GET /workflow/statistics/overview（待办数/在途实例/异常数，可选）。
