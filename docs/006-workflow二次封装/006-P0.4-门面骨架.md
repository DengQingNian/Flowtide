## 2. WorkflowFacade 方法分组（26 个）

- 发起（2）：StartProcess、StartProcessAndFirstStep
- 办结/退回/撤回/直送/重置（6）：Complete、BackToStepTask、BackTask、DoRollbackTask、CompleteToTargetActivity、DoResetProcess
- 待办/已办（2）：GetTodoTaskListByIdentityID、GetDoneTaskListByIdentityID
- 下一步（2）：GetNextUserTaskAndUserList、SaveAgreeNextActivity
- 状态/变量（6）：IsProcessDeployed、IsExistRunningProcess、GetWorkflowStatusByBusinessID、UpdateProcessGlobalVariable、GetProcessGlobalVariableByProcessInstanceID、GetProcessGlobalVariableByBusinessID
- 表单回写（1）：UpdateWorkflowDocumentByProcessInstanceIDOrTaskID
- 调整处理人（2）：DoTaskOwnerAdjustment、DoTaskOwnerAdjustmentByID
- 消息/历史（4）：GetTaskMessageListByBusinessID、GetTaskHistoryListByProcessInstanceID、GetTaskHistoryListByBusinessID、GetTaskHistoryListByTaskID
- 任务详情（1）：GetTaskInfoByTaskID（Java 方法名 geTaskInfoByTaskId 拼写在注释中保留）

统一签名 `(R, error)`：R 为协议返回（对位 Java enm.R），error 为 Go 侧 api.Error（错误码前缀 WORKFLOW-）。协议 VO 权威定义在 api 包（对位 Java workflow-api 模块），internal/workflow 以类型别名引用，避免 api → internal 循环依赖。
