## 为什么不承诺日期

旧的 483 人周估算与 6.5 FTE × 70 周存在 28 人周缺口。没有实际人员与剩余工作量依据，不能把估算直接转为发布日期。当前暂停 W42/W70 与 GA 日历承诺，待验收资料齐备后重估。

## 退出条件

### M9 停写切换与回退

- 真实 Java 样本完成停写、备份、转换、数量核对与续跑。
- Java 读取 Go 写入数据并推进通过。
- 回退演练完成，窗口、负责人、停止条件书面化。
- 单执行者启用与监控告警验证。

### M8 集群与容量

- 作业租约/抢占/幂等与故障转移。
- 实例/历史/多租户查询下推。
- 真实数据库容量基线、长稳与故障注入。

### 发布

- <code>make check</code>、<code>make race</code>、双库测试通过。
- 文档版本快照、升级与回退说明完成。
- 已知问题与安全审计记录归档。
