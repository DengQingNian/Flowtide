## 使用前检查

接入前请核对部署方式、依赖的 Java 功能和数据量。下列限制如果影响你的业务，需要先补充验收或评估替代方案。

## 1. 集群与故障转移

- 只支持单执行者；数据库独占锁阻止第二写者。
- 没有跨节点作业抢占、租约、幂等与故障转移。
- 连接丢失后拒绝提交，不保证外部副作用恰好一次。
- 禁止多个引擎共享同一个状态源。

部署时只运行一个副本，提前准备人工恢复步骤，并保证外部调用可重复执行而不产生重复结果。

## 2. Java 行为兼容

- 184 个官方方法都有路由和基础安全矩阵；六个异步变量、八个任务、十个实例/执行及十九个身份方法已有 134 个原版 HTTP 逐字段场景回放，其余方法及完整字段组合待验收。
- 错误码、分页、默认值、级联删除与租户语义未全量对齐。
- 事件子流程、补偿、事务、迁移与多实例的边界语义待 Java 对照。

接入客户端前，先用实际请求对照 Java 的响应字段、分页和错误码。路由清单可用于查找入口，行为兼容情况需要查看对应测试结果。

## 3. 持久化与查询

- JSON 快照全量写入，实例多时开销明显。
- 行仓储启动恢复是 O(数据量)，内存中维护完整状态。
- 实例/历史/多租户查询尚未下推，数据量大时退化为内存扫描。
- 无异步历史、定期清理、PITR。

试用时控制单库数据量，使用数据库备份，并避免高频调用需要扫描内存的管理查询。

## 4. 脚本与表达式

- 脚本任务仅表达式子集，不支持完整 JavaScript 语句、Groovy、Starlark。
- 表达式方法调用有白名单限制。
- 复杂模型可能部署期拒绝。

需要完整脚本逻辑时，可将业务逻辑移到 Go 委托或外部服务。

## 5. 异步与事件

- <code>variables-async</code> 已支持持久排队、重试、死信和重启恢复，仅支持单执行者。
- 外部工作项、事件注册表（Kafka/Rabbit/Webhook）未实现。
- 作业重试/死信为进程内与数据库单执行者模型，无集群协调。

## 6. SDK 与公共 API

- API 未承诺 semver 稳定性。
- <code>Config</code> 仍引用内部包类型；数据库接入改用 <code>NewEmbedded</code> 与 <code>EmbeddedConfig</code>。
- 嵌入模式只有一个写者，缺集群、租约与故障转移。
- workflow 后台扫描未在嵌入模式暴露，SQL 行仓储缺少待办数据源。
- 委托/监听器不持久化，重启需重新注册。
- 模块已发布 v0.1.1，但 API 未承诺 semver，也没有长期支持分支。

## 7. 安全

- 标准 CLI 通过 <code>-security-config</code> 接入 JWT、RBAC、身份库认证、审计和 HTTP 指标；持久审计与配置在线重载未实现。
- 证书 CN 已支持显式 RBAC 角色映射；CRL/OCSP 未实现。
- 全量权限矩阵与负向回放未完成。
- 未配置认证时端点开放，只适合开发。

## 8. 迁移

- 预检通过不代表可切换；转换只覆盖简单用户任务执行树。
- 双库临时库已通过转换核对、Go 续跑、重启及源快照还原；生产实际停写、物理备份、反向转换与 Java 增量接管尚未验收。
- 复杂作用域、作业、订阅保守阻断。
- 预检全量内存扫描，未实现分页/流式分析。

## 9. 多引擎与生态

CMMN、完整 DMN、Form/App/Content 引擎、LDAP、多数据库方言、Helm/K8s 均未实现。

## 10. 文档与状态

- 本站在构建时重新生成事实与页面，但引擎能力声明仍以仓库提交为准。
- 版本快照、英文版、搜索同义词与可访问性审计尚未完成。
