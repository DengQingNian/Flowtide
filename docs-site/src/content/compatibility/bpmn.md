## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已支持 | 解析、部署、执行与历史主路径均有实现和回归 |
| 部分支持 | 主路径可用，但语义子集、边界或 Java 对照不完整 |
| 未支持 | 未实现，或部署期直接拒绝 |
| 拒绝 | 出于安全/模型校验考虑显式拒绝 |

## 任务

| 元素 | 状态 | 说明 |
| --- | --- | --- |
| <code>userTask</code> | 已支持 | 候选人/组、签收、完成、委派、监听器、表单 |
| <code>serviceTask</code> | 已支持 | 委托名、<code>delegateExpression</code>、表达式结果 |
| <code>scriptTask</code> | 部分支持 | 仅 expression/juel/javascript 表达式子集 |
| <code>manualTask</code> | 已支持 | 直接通过 |
| <code>sendTask</code> / <code>receiveTask</code> | 已支持 | 消息/信号点对点与等待触发 |
| <code>businessRuleTask</code> | 部分支持 | 按 <code>decisionRef</code> 求值，DMN 子集 |
| <code>callActivity</code> | 已支持 | 变量继承、in/out 映射、深度限制 |

## 事件

| 元素 | 状态 | 说明 |
| --- | --- | --- |
| 启动/结束事件 | 已支持 | 消息/信号/定时启动 |
| 边界事件 | 已支持 | 定时、消息、信号、错误、条件、补偿 |
| 中间捕获/抛出 | 已支持 | 消息、信号、定时、链接、条件、补偿 |
| 事件子流程 | 部分支持 | 中断/非中断、消息/信号启动；复杂语义待 Java 对照 |
| 事件网关 | 已支持 | 竞争触发 |
| 链接事件 | 已支持 | 同名跳转与直通 |
| 条件事件 | 已支持 | 变量变化触发与显式求值 |
| 补偿 | 部分支持 | 服务/手动处理器；用户任务处理器未实现 |

## 网关与流程

| 元素 | 状态 | 说明 |
| --- | --- | --- |
| 排他网关 | 已支持 | 条件、默认流 |
| 并行网关 | 已支持 | 分叉/汇聚 |
| 包容网关 | 已支持 | 多条件、动态汇聚 |
| 事件网关 | 已支持 | 竞争 |
| 复杂网关 | 未支持 | Flowable 本身也主要停留在模型层 |
| 顺序流 | 已支持 | 条件表达式、默认流 |

## 子流程与多实例

| 元素 | 状态 | 说明 |
| --- | --- | --- |
| 嵌入式子流程 | 已支持 | 嵌套、内部并行汇聚 |
| 事件子流程 | 部分支持 | 见事件章节 |
| 事务子流程 | 部分支持 | 取消结束、取消边界、作用域销毁 |
| Ad-hoc 子流程 | 部分支持 | 并行/串行、完成条件、提前取消 |
| 多实例 | 已支持 | 并行/串行、集合/基数、完成条件 |
| 动态活动注入 | 部分支持 | 实例内独立任务，不影响主流程 |

## 数据与扩展

| 元素 | 状态 | 说明 |
| --- | --- | --- |
| 流程变量 | 已支持 | 实例/执行/任务局部/瞬态 |
| in/out 映射 | 已支持 | 调用活动与子流程 |
| 表单 Key | 已支持 | <code>.form</code> 资源渲染 |
| 候选人/组 | 已支持 | 解析、查询、身份链接 |
| <code>asyncBefore/After</code> | 已支持 | 作业、持久化、后台扫描 |
| 定时器 | 部分支持 | ISO 周期与重复；cron 时区未实现 |
| DMN 决策表 | 部分支持 | FIRST/UNIQUE/ANY/RULE ORDER/COLLECT/OUTPUT ORDER/PRIORITY |
| 外部工作项 | 未支持 | 无 External Worker |
| 动态 BPMN | 未支持 | 无 DynamicBpmnService |

## 部署期校验

- 拒绝 DTD，限制 XML 深度与大小，防止实体膨胀。
- ZIP 部署拒绝路径穿越。
- 校验元素 ID、引用完整性与元素类型关联。
- 未知扩展元素通常忽略；语义关键字段缺失会使部署失败。
- 不支持的元素应在部署期拒绝或明确降级，而不是静默跳过。

## 与 Java 的对照缺口

当前只有 Go 回归与少量 H2 黄金样本，没有 Java 执行路径回放。事件子流程、补偿、事务、迁移与多实例的边界语义仍需双向对照。实现存在不等于 Java 语义一致。
