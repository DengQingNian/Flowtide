## 高频问题

### 可以做双写或按请求灰度吗？

不可以。当前没有作业仲裁与跨引擎协调。共享库同时运行 Java/Go 会导致重复执行与状态分叉。灰度只能按独立数据库、租户或固定实例集合划分。

### 预检退出码 0 就能切换吗？

不能。预检只说明当前分析范围未发现阻断。还需要停写、备份、转换、数量核对、Java 续跑对照与回退演练。

### 转换成功就能启动 Go 吗？

不建议。转换只覆盖简单用户任务执行树；复杂作用域、作业、订阅会阻断。即使转换成功，也需要在停写窗口内核对数量与关键流程。

### 为什么 Java 作业和订阅被阻断？

当前没有受验收的作业/订阅转换器。把定时器或消息订阅静默丢弃会造成业务中断，因此保守阻断。

### 变量为什么会被拒绝？

<code>serializable</code>、未知类型、超范围整数、缺失外置字节与无法解析的 JSON 都会阻断。详见 [变量类型](/docs/reference/variables)。

### 多租户怎么处理？

<code>-preflight -tenant</code> 只过滤分析范围，不改变全库表统计。无法确认归属的数据与未知表风险仍需处理。停写检查不接受租户参数。

### 静默检查 stable=true 是否足够？

不够。它只证明窗口内未观察到变化。未知表只比较行数，同数改值无法发现。

### 能回退吗？

当前没有已验证的反向转换或 Java 读 Go 数据续跑演练；只能依赖备份恢复，且未完成正式演练。不要宣称可回退。
